# Warlock

Crafted for flow.

Warlock is the desktop shell and window system built in this repository. Its brand is **Lacquer**: mineral black, warm ivory, deep red action surfaces and luminous red details. The W is a folded sigil with neutral facets and one red focal diamond that gives the eye a stable centre. Windows open and close through a signature portal, a ring of red ember fragments that resolves into the window.
