# Warlock

Crafted for flow.

Warlock is the window system being built in this repository. Its identity combines the arcane associations of its name with geometric construction and flowing event paths.

The W is a folded sigil. Its separate gold diamond gives the eye a stable center; the surrounding facets carry the movement. Ribbons and spaced nodes borrow the visual vocabulary of reactive event diagrams. Geometric assembly provides the Elm influence. The mark is original, and does not use the Elm or ReactiveX logos.

From the repository root, run `python3 -B docs/warlock-brand/v1/preview.py` and open `http://127.0.0.1:8404/v1/`. You can also open `v1/index.html` locally; its images and fonts are bundled. The preview makes no network requests. The generated raster mark is an exploration asset; use the clean vector companion for interface sizes. The wallpaper's native resolution is 1672×941. The identity board is 1536×1024; the transparent raster mark is 1254×1254.

The current name is Warlock. Earlier Aletheia ballots, votes and source hashes remain historical evidence. The brand changes neither native authority nor the original scenario/deadline contracts. Desktop activation and release acceptance remain separate work.
