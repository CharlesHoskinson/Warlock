# Independent Astra delivery review

The workflow produced real engineering, but failed to manage delivery. It repeatedly improved one preview/recovery subsystem while the coherent desktop remained unfinished. Replace “smallest unblocked slice” with “smallest user-visible slice on the release critical path,” and accept original scenarios as soon as their own evidence supports acceptance.

Its first slice explicitly directs preview-provider work. Nothing limits consecutive infrastructure iterations or requires a finished user journey. This creates a rational local optimum: another ownership refinement is always available. ## Replacement execution rules

* **Stop:** automatic full-directory derivatives, repeated broad reading, reflexive model campaigns, publication-only follow-up commits, and additional CONTROL contracts without a demonstrated original-scenario blocker.
* **Start:** one integration owner, one product implementation slice in progress, one native campaign at a time. Before coding, record original IDs, visible behavior, touched paths and the smallest discriminating checks. Integration is part of the slice, not deferred work.
* **Retain:** single authoritative policy, native effect authority, ABI identity, protected isolated native runner, immutable deadlines, Unknown/no-replay semantics, draft preservation and failed evidence. Never lift the preview curtain merely to obtain a screenshot.
* Compile touched programs; run focused behavior checks. Escalate to broader regression when shared interfaces or a failure justify it. Use Quint for changed concurrency invariants, not mechanically for a label or layout change. Run original full campaigns at integration milestones on one frozen tuple.
* Keep historical evidence immutable. Use Git commits/worktrees for future source versions and manifests referencing unchanged content; do not rewrite held paths. One concise current-state file plus an append-only evidence index replaces replicated narratives.
* Every hour report scenario closures, visible behavior delivered, concrete blockers, next product slice, and measured token/time usage if available. Two consecutive iterations with neither a closure nor visible behavior trigger reselection. Native-slot contention permits independent GUI work; it does not authorize another endless infrastructure lane. No new plugin is needed.
