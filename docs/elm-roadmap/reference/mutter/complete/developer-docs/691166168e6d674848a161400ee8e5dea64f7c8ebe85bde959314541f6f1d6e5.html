A ClutterContent which draws a shaped texture

A MetaShapedTexture draws a CoglTexture (often provided from a client surface) in such a way that it matches any required transformations that give its final shape, such as a MtkMonitorTransform, y-invertedness, or a crop-and-scale operation.
