Description [src]

Creates a new ClutterPaintNode that will paint the passed texture.

This function will take a reference on texture, so it is safe to call g_object_unref() on texture when it returns.

The color must not be pre-multiplied with its CoglColor.alpha channel value; if color is NULL, a fully opaque white color will be used for blending.
