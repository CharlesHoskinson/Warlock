Description [src] 

final class Meta.BackgroundActor : Clutter.Actor
  implements Atk.ImplementorIface, Clutter.Animatable {
  /* No available fields */
}

This class handles tracking and painting the root window background.

By integrating with MetaWindowGroup we can avoid painting parts of the background that are obscured by other windows.
