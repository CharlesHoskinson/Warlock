## Publication and remaining scope

The owner explicitly requested merging all current work to GitHub, then added documentation/design revisions and this three-reviewer audit. Recommendations to wait for another permission before a development merge do not override that authorization. Main remains a development branch; merging unfinished work does not qualify or deploy a release.

The publication batch includes the current candidate and its draft evidence, revised design/docs/plugin references, and existing tracked historical drafts preserved byte-for-byte. Historical draft changes are retained separately and are not imported into the active runtime or counted as delivered features. Disposable profiles, build caches and unmanaged old experiments remain local.

Actual feature implementation is tracked in [FEATURE-COMPLETION.md](../../warlock-roadmap/FEATURE-COMPLETION.md). Native, accessibility, IME, hardware, resource, usability, packaging and rollback obligations remain open. Unadjudicated requirements do not establish missing code.

Link/browser checks and package compliance are recorded in `verification.json`; they qualify the revised documentation entrance only. The old v6 finish receipt stays scoped to its original snapshot. No full WCAG, native AT or release verdict is inferred.
