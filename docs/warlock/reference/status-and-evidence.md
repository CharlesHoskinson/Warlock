## Vocabulary

- **Proposed:** a source finding, hypothesis or design awaiting selection and checks.
- **Implemented / component-verified:** code and bounded compile/model/replay evidence exist; scope is explicit.
- **Scenario accepted:** its own original given/when/then and verification are independently satisfied on the recorded tuple.
- **Requirement accepted:** all applicable original obligations are adjudicated; this is not release acceptance.
- **Cleanup passed:** owned teardown completed; the tested operation and normal process exit can still fail.

Preserve immutable failed/partial evidence. Reusing an older accepted tuple needs explicit source relevance; a source hash appearing in a report is not proof that every file was consumed. Independent bridge acceptance is valid where permitted, but AT, physical presentation, budgets and deployment require the observations each original asks for. Check counts, commits, diagrams and administrative updates are not GUI feature counts.
