Contributing

Build on the source, verify behavior and make evidence reviewable.

Work from the source

Use the GitHub contribution guide for the project workflow, source entry points and checks. This external reference opens only when selected.

Ground changes in evidence

Use the original requirements and source as behavior authority. Record the scenario and observed result, and distinguish native evidence from browser fixtures and frozen catalog specimens. Run checks appropriate to the change and report remaining verification.

Contribute to the design language

Study the foundations and component guidance alongside the current implementation. Preserve accessible names, keyboard access, stable targets and outcome boundaries when changing a surface.
