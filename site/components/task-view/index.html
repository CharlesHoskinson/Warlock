Task View

Task View presents an inventory of workspaces and window families.

Overview

Task View presents an inventory of workspaces and window families.

Anatomy

A flat sequence contains Close, All windows, workspace filters, family rows and applicable move, navigation and recovery controls.

Workspace filters and family rows are ordered controls. An empty inactive workspace can expose a Go action; eligible families have a separate Move action. These controls are not draggable columns.

States

A selected filter and the observed active workspace are independent facts. Empty workspaces remain visible.

  • All windows: the inventory spans workspaces.
  • Workspace filter: only that workspace’s inventory is browsed.
  • Active workspace: an observed desktop fact, independent of the selected filter.
  • Empty workspace: remains visible and can offer Go when eligible.

Specimen

Real Elm interface. Simulated desktop. Client window interiors are fixtures. Load the desktop only when you want to explore this component.

Open the full desktop scenario

Behavior

Filtering changes the inventory, not the desktop. A family activates or restores; an eligible empty inactive workspace has a separate Go action. Move opens destination selection.

Select a filter to browse without changing the desktop. Select a family to reveal its workspace and activate or restore it. Go navigates to an eligible empty workspace; Move starts the separate destination flow.

Accessibility

Buttons retain their source order and names. Selected filters expose pressed state, and labels wrap at enlarged text sizes.

Content

Describe the active workspace as an observed fact. Do not imply workspace columns, thumbnails or drag operations.

Use the workspace identity in each filter and destination label. An empty inventory is not an error and should not be described as a missing workspace.
