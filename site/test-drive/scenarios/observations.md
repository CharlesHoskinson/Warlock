# Scenario observation integration

A scenario completes only after the current epoch's admitted presentation has been acknowledged by the relevant renderer for that exact publication. The snapshot supplies the mode, the surface's applied publication and the current control identities. Tour checks also use selected controls and the search query. These are presentation facts, not authorization to dispatch actions.

Status and recovery selects the simulated refusal policy and uses the host's supported new-instance intent. The Elm application receives the launch refusal and presents its own notice and refresh control. The scenario waits for the acknowledged Applications presentation and its Refused status, then restores the normal service policy. Refresh reads the catalog; it does not repeat the launch. A confirmation is never accepted by a scenario or tour.
