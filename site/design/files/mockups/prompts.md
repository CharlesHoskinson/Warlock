# Files illustration prompts

Apache-2.0 project material. Generated with the image generation tool. Both studies show a ready observed peer at `/home/warlock`, quiet destination rows and a focused explicit path entry. Images are visual studies; the specimen and tokens define the renderer.

1. Generated concept study, `files-night.png`: Night Warlock Files popup, 480px wide, near-black surface, warm ivory labels and restrained red. Source order: Files, Close Files menu, Refresh Files state, recessed current location, unboxed Home and collection rows, Folder path field with blue focus ring, Open folder and its detail. No cards or thumbnails.
2. Generated concept study, `files-dawn.png`: The same ready scenario in Dawn, warm white surface and dark text, with deep red action and a blue field focus ring.

The generated layouts include decorative icons and placement differences that the real renderer does not project. They do not define controls or interaction.
