# Taskbar image studies

Both illustrations use the built-in image generation tool. They are visual studies, not source-rendered screenshots. The source-shaped specimen and numeric specification control the implementation.

1. `taskbar-night.png`: wide straight-on Night taskbar study. Prompt: “One continuous text-first toolbar in this exact left-to-right order: Refresh window status, Editor with detail Pinned; Active; Attention, Files with detail Pinned launcher, Terminal with detail Attention; 2 windows, Browser with detail Minimized, Applications, Task View, Switch windows, Notifications, Files, System, Settings, then a trailing status reading Restore: not confirmed for selected window. Editor has a neutral top marker, red bottom marker, and warning triangle beside its detail. Terminal has the same warning triangle. Black mineral surface, ivory text, muted warm gray details, deep red active wash. Flat opaque surfaces.”
2. `taskbar-dawn.png`: generated as an edit of image 1. Prompt: “Preserve the exact composition, scale, source order, all labels, all details, warning triangles, top and bottom markers, and trailing status. Only change the palette to warm paper, ivory, dark ink, pale red selection, deep red marker and warning brown. Do not add icons, separators, controls or words.”

Both images omit the keyboard disclosure and approximate marker dimensions. Night understates the selected fill. They illustrate the shared fixture and do not establish actual renderer behavior or exact colour values.
