# Mockup provenance

Image 1, `switcher-night.png`, is a built-in image generation Night study. Image 2, `switcher-dawn.png`, is its generated Dawn counterpart using image 1 as the visual reference. Both show Files as candidate and the same single-column scenario. The images are illustrations, not native or browser evidence. The generator misspells the Activate label in both images, adds option icons absent from the renderer, and omits the focus ring in Dawn. Both are captioned “Generated concept study” in the specimen. The source-faithful HTML governs content, structure and focus. The extra file `generated-r3-1.png` is an additional generated draft, classified and hashed in [the manifest](manifest.json).

Prompt 1: Create a crisp Night desktop switcher with exact heading “Switch windows”, options Terminal / Open, Files / Selected and Browser / Minimized, and actions “Cancel window switcher”, “Previous window”, “Next window” and “Activate selected window”. Mark Files with a selected wash and neutral brackets. Put a blue focus ring on Activate. Show independent focused-window and active-application edges. Use opaque black, ivory and red, with no thumbnails or timestamps.

Prompt 2: Create the Dawn counterpart of image 1 at the same scale and layout. Preserve the single-column rows and exact labels. Use warm paper, dark ink, pale selected wash and deep red action fill.
