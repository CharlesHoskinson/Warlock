# System and menus

## Overview

System, window actions and application actions are immediate shell surfaces on the glass panel: System is a quick-settings flyout, window actions a compact Windows-style context menu, and application actions a jump list. System presents the current volume, network, power and session facts with the operations admitted by the service. Window actions present the current provider's menu. Application actions present the selected catalog entry's declared actions and recent files. Inline System confirmation stays in System.
