# Additive EARS requirement

## WARLOCK-UNISSUED-001 Current demand liveness
WHEN the current picker reopens after an unissued intent expired and the original
physical pool has drained, the dynamic host SHALL visit unissued current subjects
before resuming previously issued actors, without bypassing exact presentation,
native source, receiver, cutoff, physical capacity or terminal ownership checks.

### Scenario: actual third image after expiry
The first picker displays two actual images and expiry for a third. After exact
drain and a later picker lease, the third receives its first actual capture and
image using the successor's original cutoff, then settles through exact proof
and acknowledgment in the same host and owning native ABI.

### Scenario: retained physical owners
Priority cannot reclaim either still-owned item, acknowledge another job,
renew a same-stamp cutoff, or capture a disabled/foreign picker subject.
