# Design

A private QA flag holds a GIO reader on the same native icon endpoint used by WebKit, after the original actual preview image is displayed. Its immutable own token comes from native enrollment, never a file stimulus. The private UID0700 nonsymlink directory and UID0600 regular single-link bounded nonsymlink file use the existing exact hold/probe/release grammar. Hold/probe delays existing native polling and queues at most four original validated undispatched Elm effects; ACK delivery remains original. Probe performs real held/new icon reads before releasing delayed policy. No alternate grant, native scope, URI, clock, deadline or frontend decision is supplied.

Release physically closes the held reader, accounts remaining immutable icon asset bytes, then delivers original native source polling and original queued effects once. Exact native locked denial conceals title/icon in the same Elm state. A separate private DOM report/independent WebKit snapshot can observe Preview unavailable and zero icon elements while mapped/exported frame resources have retired and the original native producer remains pending under the private session lock. Native authenticated lock query is read-only evidence; no inferred terminal receipt. Original mapped/exported/producer/journal ownership, deadline, original ACK and normal exits remain required.

Icon endpoint teardown refuses held readers and reports its own actual assets/readers/bytes zero after physical close. Existing physical0/journal0 text continues to describe the original preview broker; static metadata icon bytes have separate accounting and cannot be mistaken for preview frame retirement.

Metadata revision domain resets only on a valid native binding change, clearing old title/icon and retaining old cleanup. GTK theme change only marks native metadata cache dirty; existing polling publishes a new correlated metadata delivery without a capture, timer or deadline renewal. Native theme/rebinding qualification remains separate from controlled compiled checks. Ordinary product multi-entry enrollment, full preview13/state/fidelity/clock/hardware/resources and all S01–S16 release gates remain open.
