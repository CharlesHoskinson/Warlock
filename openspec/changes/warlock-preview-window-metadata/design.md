# Design

The native metadata snapshot has exact protocol/binding/request correlation and a positive lossless revision. Every window has one unique incarnation and bounded UTF8 labels. Missing subjects cannot borrow a replacement. Metadata events carry exact binding, subject, revision, title, application, iconKind and nullable opaque token. Their delivery revision is the strictly increasing authenticated snapshot request identity; the separately validated snapshot catalog revision detects title/application changes during polling. A fresh seed may publish a new privacy-scoped icon even when catalog revision is unchanged. Neither counter resets during the native actor lifetime. Elm rejects malformed, foreign, stale and duplicate revisions without commands or policy changes.

The native icon endpoint resolves application desktop icons through GTK, distinguishes application/generic/unavailable, and bounds PNG assets (64KiB each, two retained assets, four readers). These local admission bounds are not measured S02 production budgets. An asset belongs to the provider's lifetime/session/frontend, incarnation, privacy revision and application identity, and to its registered popup view. A random canonical 64-hex token exposes no path. Every new and held read validates current native authority independently of frontend progress; cache headers request no-store. Physical reader references and bytes remain charged until consumption/close; teardown refuses live readers. Icons add no capture, renewal or independent policy authority.

Exact SourceDenied locked events retain concealment in the existing Elm state; malformed/stale/foreign events and metadata updates cannot alter it. Only a valid coherent fresh unlock scope may clear concealment. Original scope, clock, expiry, cleanup commands and terminal ACK are retained. Metadata failures do not relabel transport Unknown or suppress original lifecycle events. Current title/application changes are observed on existing native polling; no extra timer or capture is introduced.

Native qualification must inspect the actual popup DOM and independent WebKit PNG for an actual title and resolved application icon after source loss, absence of old/foreign preview pixels, lock concealment and held/new read refusal. Component/replay checks are separate evidence. Hardware presentation, general enrollment, measured budgets, full S09 and full release remain open.
