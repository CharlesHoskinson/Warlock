## Why

Warlock has a browser-accessible desktop and design reference that shows the interface and its operating model together.

## What Changes

The site specifies a full-viewport simulated Omarchy desktop running compiled Elm, a deterministic host, guided exploration, an interactive architecture view and design language pages with direct links to desktop components. The site is accessible, self-contained and deployable beneath the GitHub Pages sub-path.

## Capabilities

### New Capabilities

- `warlock-design-site`: simulated desktop, component documentation, guided tour, architecture and publication.

## Impact

The site uses local compiled Elm bundles and simulated observations. Client interiors are fixtures. Browser demonstrations do not qualify native GUI behavior. The architecture view identifies its model and does not override the Elm and Haskell production-language contract.
