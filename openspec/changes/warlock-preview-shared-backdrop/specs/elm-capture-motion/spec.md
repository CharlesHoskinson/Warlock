## ADDED Requirements

### Requirement: Explicit shared source enrollment
The system SHALL enforce the shared generated source contract.

EARS WRLK-SHARED-BACKDROP-001: WHEN generated backdrop previews are enrolled, the full shared Main/Bar/Popup provider SHALL decode an explicit generated native source with its own authenticated child grant, canonical opaque native color, exact lifetime/subject/clock and original capacity; transparent and generated capture planes SHALL remain distinct.

#### Scenario: Foreign or cross-plane scope
- **WHEN** a scope uses another child binding or aliases transparent source kind with generated metadata
- **THEN** the shared decoder refuses enrollment without frame authority

### Requirement: Original immutable capture and family coverage
The system SHALL enforce the shared generated source contract.

EARS WRLK-SHARED-BACKDROP-002: WHEN Elm issues Acquire for the generated source, the native allocator SHALL capture and import FD4 under the original job/context/native two-second deadline, validate color/crop/scale/CRC/seals and require complete family fidelity and coverage before offer/fence admission.

#### Scenario: Incomplete generated family
- **WHEN** a client-only offer or incomplete family fence is submitted
- **THEN** the original Elm state and commands remain unchanged

### Requirement: Current source and historical pixels
The system SHALL enforce the shared generated source contract.

EARS WRLK-SHARED-BACKDROP-003: WHEN actual generated native color changes while an independently owned image remains retained, the system SHALL update current native source facts under the same typed plane and SHALL preserve the original frame handle/job/expiration, show Historical preview and SHALL NOT recapture or renew that frame.

#### Scenario: Native color revision while image retained
- **WHEN** native generated white changes to native generated black with unchanged root commits
- **THEN** the source epoch advances and the new admitted presentation shows the original URI/image/job as historical with one acquisition

### Requirement: Physical cleanup and exact receipts
The system SHALL enforce the shared generated source contract.

EARS WRLK-SHARED-BACKDROP-004: WHEN the original generated frame expires or loses authority, the system SHALL close its physical mapping and FD, release its exact export transfer, retire its producer and retain the terminal receipt until exact Elm acknowledgement before freeing proof ownership or admitting new capture.

#### Scenario: Expiry after reopening
- **WHEN** the original generated frame expires under a newer presentation lease
- **THEN** the original frame expires without renewal and physical retirement precedes the exact original job terminal ACK

### Requirement: Actual pixels and unchanged geometry
The system SHALL enforce the shared generated source contract.

EARS WRLK-SHARED-BACKDROP-005: WHEN qualifying shared generated previews, the verifier SHALL decode actual WebKit output against independently observed native generated blur color, derive displayed dimensions from unchanged native crop aspect ratio and CSS bounds, retain failed fixtures and SHALL NOT substitute renderer-only pixels for shared GUI evidence.

#### Scenario: Height limits preview width
- **WHEN** a native334x254 crop is displayed under grid160 and max-height120 constraints
- **THEN** the actual158x120 image retains native crop dimensions and exact URI while the prior fixed160-width fixture remains failed evidence

### Requirement: Typed source loss
The system SHALL enforce the shared generated source contract.

EARS WRLK-SHARED-BACKDROP-006: WHEN the owning native generated source becomes unavailable, the system SHALL decode only the declared exact typed denial for that source plane, revoke URI authority independently of Elm delivery and preserve original physical ownership and cleanup receipts until actual retirement and ACK; unknown errors SHALL NOT imply Refused or permit automatic replay.

#### Scenario: Generated color becomes nonopaque
- **WHEN** the exact owning generated source returns preview-family-backdrop-source-unavailable
- **THEN** the existing SourceUnavailable event settles preview authority while original physical ownership follows actual cleanup and retained exact receipts
