# Layered-window design language

The three-member design council unanimously accepted fourteen additive EARS
requirements and thirty OpenSpec scenarios in one exact hash-verified packet.

- [Decisions](DECISIONS.md): color, glow, shadow and shading roles and preferences.
- [EARS](EARS.md) and [OpenSpec](../../../openspec/changes/warlock-layered-window-language/specs/warlock-layered-window-language/spec.md).
- [Tokens](tokens.json), [exact consensus receipt](consensus-receipt-v1.json) and
  [implementation notes](IMPLEMENTATION-NOTES.md).
- [Workplan](WORKPLAN.md): fresh catalog/native adoption and original qualification.

Neutral shadows show separation. Opaque owned-chrome shading groups layers.
A steady violet primary halo marks the confirmed keyboard recipient; an Active
application contour and Candidate tile marks remain independent. Weak short
Family brackets identify admitted relationships. High contrast and effects-off
retain the same information through opaque shapes and labels.

Omarchy's effective commands, keybindings and user overrides retain their
meaning. The earlier thirty-contract design consensus and full GUI release gates
are unchanged. This packet establishes design targets; visual implementation
and native qualification remain open.
