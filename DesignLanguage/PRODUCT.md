# Warlock product context

Warlock is an Elm-based Linux window system under development. It aims to keep user intent, visible state and native behavior in agreement. One immutable Elm controller owns ordinary desktop policy; typed messages describe changes and native authority determines what actually occurred. Display surfaces are read-only projections. Modern Elm uses Model/Update/View, with inspiration from functional reactive programming rather than the historical Signal API.

The desktop serves people doing sustained windowed work with keyboard, pointer and accessible input. Current candidate surfaces include taskbar groups, window picker/previews, launcher search, window-action menus, Alt-Tab, Task View/workspaces, snap selection, appearance/motion settings, notifications, system controls, Files integration, jump lists, recovery and connection status. Pin/MAX is an unfinished draft. Real compositor input, frames, resource lifetime, AT/IME, hardware, performance, recovery and deployment still require their original release evidence. The catalog does not establish competitive superiority or native acceptance.

The requested website is a repository-owned design catalog like Material Design's documentation: explain Warlock's philosophy and brand, foundations, all current widgets, interaction/outcome states, patterns, accessibility, tokens and evidence. Readers include users evaluating the system and developers implementing consistent controls. Success means finding a widget, understanding its behavior and limits, and exercising faithful labeled examples. Existing Warlock identity and original GUI contracts are fixed constraints.
