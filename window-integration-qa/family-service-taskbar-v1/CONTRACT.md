# Native family service with actual taskbar endpoints

This campaign must test the complete staged family scene service with actual
Wayland compositor captures, the unmodified installed taskbar QML and real
native window commits. A synthetic icon rectangle or a fake desktop adapter
cannot satisfy it. Offline daemon tests, held generated pixels and prior
single-window native motion are prerequisites with separate scopes.

## Owned environment and launch

Root owns the single native slot. Launch through qa_run.py/core1 with the frozen
private Weston headless GL host and mandatory private Wayland Aquamarine. Use
one short owned0700 /run/user/$UID/wqa/<4hex> runtime, no Xwayland unless an
explicit separate X11 campaign, and no main bus/display/IPC/environment fallback.
Observe the original desktop before and after without input or restoration.

Copy the packaged shell source, installed widget_v65 files and their native/QML
dependencies into the reviewed packet. Use a private OMARCHY_PATH and private
HOME/config/data/state/cache. Enable only hoskinson.windows on the left bar;
disable idle and unrelated plugin/services in the private configuration. Copy
the reviewed helper sources into private HOME without linking mutable user
catalogs or writable configuration. Do not alter installed shell/plugin/helper
files. Start the actual qs shell with the exact private config/display. All
shell IPC must select that config and display, never the main running instance.

Before any scene request, verify actual plugin/native modules, selected private
compositor PID/start/socket peer, shell PID/start/config and complete IPC replies.
Require the taskbar's production motionTarget response for each exact owned
window identity, positive visible icon extent and matching output/monitor.
Retain the production taskbar diagnostic state and screenshot proving the
endpoint is a rendered icon. No target override, fitted coordinates or manual
metadata publication is permitted.

## Required actual native transaction

Create a public Qt owner/modal family and an independent peer with exact native
identities. Capture normal geometry, workspace, pin and focus/input state. Start
the explicit staged native service with exact frozen producer/core bytes and
selected compositor authority. Verify durable receipt before accepted ACK,
complete ordered family capture/source digest vector, actual output generations,
matching own swap/presentation and endpoint commit. Minimize all and only family
members, keeping the peer usable. Restore their exact stored destination,
geometry and per-member pin state. Minimized previews and actual taskbar presence
must survive; no scratchpad navigation is introduced.

Exercise both interior reversals, a third request during deferred context
lookup, reduced motion before/during a transition, stale/closed identity refusal,
independent families and membership/geometry replacement. Old callbacks must be
refused after newer receipt. Interrupted contexts/transport and shutdown must
produce one explicit terminal outcome with no native fallback or duplicate
commit. Journal/source/image/actor ownership must survive the accepted recovery
policy; unresolved native recovery remains failure rather than auto-replay.

Collect timestamped receipt, queued reversal, shared-clock presented origins,
first reversed presentation and actual frame gaps. The retained 54/61ms moving
presentation failures remain open. Readback diagnostics may stall and cannot
prove cadence. Actual physical 240Hz, mixed/scaled/transformed output and
translucent backdrop coverage require their separate complete-image/timing
campaigns; success here cannot substitute for them.

## Teardown and acceptance

Stop the exact owned service and renderer normally, then owned Qt/input/shell
clients, verify no unexpected helper descendants, then unload native modules
before Hyprland, Weston and bus. Preserve failure reports; no retries without a
fresh reviewed revision. Check every frozen source/hash/link, all original
desktop preservation fields, exact owned process lifetimes/socket/runtime
removal and archived parent/compositor transport logs. Forced shutdown,
unexpected helpers, partial family coverage, stale authority, missing actual
taskbar endpoints or any native/raster/timing failure must remain failed.

No native launch is authorized by this contract alone. Full Windows parity
requires the complete requirements.md matrix and stronger device/app evidence.
