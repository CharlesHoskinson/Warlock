# Real per-window menu observation

The campaign captures native member tokens and menu generation through real preview right-click or selected-member physical Menu input. A readonly diagnostic query cannot open a menu, send Pin, create an input receipt or count as frontend acceptance. Readonly expectations may query current native identities; only the real popup's capture-helper result provides the menu's full captured token.

Before the Toggle row press, require the same actual QS process/config, native layer owner/namespace/visible allocation, current menu generation/full typed token, visible enabled row labelled Toggle pin and integer point inside its witnessed allocation. Real virtual-pointer move must have exact cursor and native selected layer; then real button down and release. For Return, require the actual selected popup keyboard surface owner plus physically correct balanced keyboard chord, not Core focus alone. Pointer input and keyboard input are separate authorities.

Record raw menu, native layer, Core/Seat focus, owner/member and helper observations before every assertion. Bind a complete native receipt to that exact action-helper PID/start/exe/argv/root, one owned durable file, preselected config/private socket/peer/EOF and full captured owner token. The current menu cannot be replaced or closed between capture and completion; changed object generation, member lifetime, output/layout/row or config invalidates it. A refused or uncertain helper cannot become a completed mutation. No retry or direct native invocation can substitute for the input.

After release require actual latest per-member pin state, protected stacking band and exact independent peer/member bits, geometry/workspace/monitor/fullscreen. Preserve distinct entry Core focus and actual Seat keyboard surface owner of the native Pin invocation; UI menu setup may legitimately change keyboard ownership before the command and is recorded separately. Feedback lifecycle and popup closure are observed; no historical menu label or post-handler label can replace captured identity.

Genuine ServiceResponsive13 minimize/restore remains a distinct UI operation through the existing product route; direct request_runtime is not frontend acceptance. Validate normal helper/actor/cache teardown and preserve current pin bits and independent family members. This contract authorizes no main desktop writes, native run or frozen packet change. Root owns actual execution and acceptance.
