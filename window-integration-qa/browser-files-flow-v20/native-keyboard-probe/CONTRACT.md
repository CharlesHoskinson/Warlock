# Private read-only keyboard probe derivative

Original qt-modal-private-v9 probe state, identity representation, target/modal,
button observer, authorization and description remain byte exact after removing
the explicit additive keyboard block. Fresh keyboard_state/events are separate
APIs: public strong Seat surface/resource/keyboard locks and public surface-query
owner resolution. The existing original uintptr address representation remains;
no new opaque cast is introduced. No focus/input/cancellation/keymap writes occur.

Native ABI compilation uses -Werror and retains600 exact source dependencies.
Frozen closure includes original V9 compiler/host authority and fresh binary,
source/dependency bytes, modes and links. Loading is reserved to root's exact
owned private runtime/compositor/scope/UID/0700/core-limit/API-hash guards.

Events are bounded512 keycode/state/time/sequence snapshots at the observer point.
Symbols refer only to the actual Seat map at that instant; cancellation is also
only at observation. Copied primary InputManager shows this precedes final
selection/delivery. Actual installed revision equivalence is unproved. No event
is a DOM input, no missing/foreign surface owner is inferred from core focus,
and no probe result supplies a new feature acceptance or native input route.

Listener resets before unload. Original button listener/lifecycle remains exact.
The derivative has been built but never loaded by its author; root owns native
lifetime/mapping/API tests and teardown. Original V9 and every prior browser
packet remain immutable.
