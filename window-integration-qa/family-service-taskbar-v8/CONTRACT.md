This campaign must test the complete staged family scene service with actual
Wayland compositor captures, the unmodified installed taskbar QML and real
native window commits. A synthetic icon rectangle or a fake desktop adapter
cannot satisfy it. Offline daemon tests, held generated pixels and prior
single-window native motion are prerequisites with separate scopes.

Before any scene request, verify actual plugin/native modules, selected private
compositor PID/start/socket peer, shell PID/start/config and complete IPC replies.

## Teardown and acceptance

clients, verify no unexpected helper descendants, then unload native modules
before Hyprland, Weston and bus. Preserve failure reports; no retries without a
fresh reviewed revision. Check every frozen source/hash/link, all original

taskbar endpoints or any native/raster/timing failure must remain failed.

No native launch is authorized by this contract alone. Full Windows parity
requires the complete requirements.md matrix and stronger device/app evidence.
