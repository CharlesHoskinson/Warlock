# Causal telemetry contract before fixture instrumentation

This stage runs the unchanged v7 candidate. It must not implement the proposed
owner lifecycle repair or change authoritative pure State. Native attempt 3
remains failed and unclassified. No main bus monitor or native run is authorized.

The actual independent client's GDBus message filter records received wire
headers/serials/timestamps before main-context signal delivery. The filter returns
the identical message and makes no protocol call. The existing subscription
callback records its actual dispatch time/count and the wire arrival snapshot;
it does not clear history, synthesize signals, or force a GLib drain. Automatic
command begin/end logs record actual requests/replies. All logs are private0600
inside the fresh owned0700 attempt. An actual private dbus-monitor records daemon
owner-change and PointerLocator signal/call chronology. It is scenario-owned and
stopped before normal maintenance; main D-Bus is never used by that monitor.

The churn gate retains actual baseline/after callback lists, actual release and
reclaim replies and cursor/time facts. No sleep/service barrier replaces that
assertion. A signal arriving before owner loss but dispatched later is in-flight
history; a newly emitted stale signal after owner churn without a new authorized
query is a bridge violation. Ambiguous ordering remains unresolved. Failed or
successful telemetry cannot erase previous failures or prove a policy repair.
