# Detached-parent contract/model independent review

`model-review.json` records PASS70 named cases and2,000×100 traces before runtime
changes, eight exact source hashes unchanged, and four runtime byte files still
equal frozen V12. This accepts the fresh contract/model refinement only. The
implemented helper and actual Browser/Files input result require later review.

The original68-case model omitted a separate runtime identity token; the final
model now distinguishes runtimeToken from rootToken and rejects valid runtime
replacement during verify and post-disk confirmation. Negative lookup must use
the opened nofollow profile directory descriptor verified against the original
live profile anchor. Its descriptor fstat and named path must agree before and
after exact single-component nofollow lookup. Preserve actual ENOENT errno,
filename and the full canonical requested path. This ties the observed absence
to the selected current directory object without inventing historical parent
metadata. Present, absent, symlink/dangling/special and other error states are
distinct; state changes or replacements revoke authority.

`retained-v12-attribution.json` independently replays the raw actual FD,
fdinfo/mount/maps encodings and live root/directory identities. Both raw samples
have only parent ENOENT. The exact regular owned0600 unlinked4MiB O_RDWR FD7,
device/inode/target and VMA are retained. Strict V12 failure and unobserved
post-disk proof remain failures; these samples cannot authorize V13 input.

The retained upstream persistent-histograms source's LocalMemory switch branch
does not call the mapped-file constructor. Its subsequent allocator Get() can
reuse an existing allocator. A requested feature flag and these source bytes
therefore establish neither which installed Brave branch executed nor who
deleted a directory. No source-branch equality, historical inode/mode,
histogram-content or deletion-actor claim is made.

Precreating/holding a parent directory would change the original empty-profile
fixture and still would not bind a surviving data FD to that directory's old
inode after replacement. The bounded negative-state refinement keeps the
actual producer FD/VMAs/current profile/runtime proof meaningful without that
unsupported historical claim. All executable/deleted disk-code predicates,
exact raw root hash/line binding, aliases, sandbox/network, actual browser
draft/caret and unchanged Files callback/reload/focus, normal cleanup and main
preservation gates remain mandatory. Frozen V12 and its prior external review
were not edited; no native or main operations were performed.
