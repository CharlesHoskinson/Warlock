## Observation timing and source attribution

The copied primary InputManager onKeyboardKey emits the cancellable key observer
before its capture/keybind/IME checks, setKeyboard and sendKeyboardKey. The probe
therefore labels cancellation and Seat symbols strictly at that observation
point. Its symbol is read from the actual active Seat keyboard at that instant,
which may differ from the event source's keyboard or the later selected delivery
keyboard. Neither a key event nor ACK0 proves a trusted DOM input. Missing owners
are retained without substituting core focus. The buffer contains at most512
private observations; sequence numbers expose truncation, with no claim of a
complete global event history. The copied primary wtype source describes custom
per-process keymaps; equivalence to the installed binaries is unproved. Actual
kernel argv/executable and actual Seat metadata remain the diagnostic evidence.

Each native sample saves both Browser start observations, all actual private
clients, the unchanged native dictionary, Seat dictionary and bounded events
before checking exact captured Browser address/stableId/PID and private instance
selector. An identity change refuses; a different Seat owner is diagnostic and
never repaired. The fixed actual CDP session remains the original session used by
the unchanged DOM query. Every failed equality poll is saved before the existing
wait loop tests it. No diagnostic field changes an original feature predicate.
