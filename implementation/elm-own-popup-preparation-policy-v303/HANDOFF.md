## Concrete production interface

`Host` is the trusted native-host stamp: actual host PID/start, current owned popup wl_surface resource, view/generation/topology, current publication/lease and Menu ID. `Native` independently matches that exact stamp and full native Binding plus exclusiveOwnGrab and negative sessionLocked/exclusiveLayer/dragging/modal causes. Existing wire has no adequate cause authentication; root305 must provide it before any adoption.

`Snapshot` binds native lifetime/session/frontend, target incarnation, authority output generation, workarea revision, independent legacyRevision and geometryRevision, respective original read IDs and full normalized stable structural fields, selected action, current eligible and actual action allowed. `output` is the existing native context output generation, not physical monitor ID (which may be0 and belongs in structural fields). The normalization must preserve all target/family/placement/constraints/output-owner fields and omit only independently proven own-blocker-derived eligibility/capability changes. Neither a loose fingerprint nor this caller API validates that normalization itself.

- `closed now token host nativeFence freshLegacyID freshGeometryID model` consumes only the exact original stamp and host close/sync fence. Read IDs must be positive, distinct and newer than their original stream IDs. Returns `Observe`; it does not itself send observations.
- `reply now token isGeometry request snapshot model` admits only matching original binding/target/output/workarea/action/structural state and requested stream ID. Actual fresh eligible **and** allowed must hold; revisions compare only within their native stream namespaces. Both replies may arrive in either order carrying the other stream's cached original revision. Their independently accepted current context fields are assembled; one `DispatchFresh token snapshot` removes the slot. Duplicate/late replies cannot repeat it.
- `cancel`/`expire` consume only the exact token and preserve proof retirement. Caller must route disconnect, scope/lease retirement, external blocker and prepared cancellation into these existing lifecycle decisions.
