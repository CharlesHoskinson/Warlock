# Native root and popup revision observer

The accepted native1011 renderer trace changed popup pixels from cyan to yellow while the old root-only content context remained identical. Preserve that frozen failure of production sufficiency and both existing client and root-monitor meanings.

POPUP-01: WHEN the owning native popup scope is sampled, its producer SHALL derive the enrolled root/subsurface tree and every currently rendered native-owned popup/subsurface tree from the exact owning core; no frontend fact may supply pixels, membership, clocks or revisions.
POPUP-02: WHEN a sampled popup commits, changes native position, maps/unmaps, is destroyed or a sampled resource address is reused, the observer SHALL advance or invalidate its distinct monotonic content context before new publication without retargeting an old identity.
POPUP-03: IF ownership, native geometry, sampled applied revision, identity capacity or graph bounds cannot be proved, the observer SHALL refuse the new scope without changing prior client/root-only semantics or any physical retirement obligations.
POPUP-04: WHEN a production capture is considered, this observer SHALL NOT qualify production family/decoration/modal/hardware coverage by itself; capture must bind the complete applicable current context at both boundaries and retain original deadlines.
