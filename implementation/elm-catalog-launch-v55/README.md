# Desktop catalog and native launch component V55

This is a bounded S07/S11 prerequisite, awaiting authenticated host/broker and GUI integration. It does not complete a requirement or a sprint.

`native/taskbar_catalog.py` is a byte-identical copy of the existing taskbar-v3 parser. Its 24 original tests are retained. Catalog presentation exposes only desktop IDs, names, icon hints and WM class hints. Paths, Exec, actions and terminal metadata remain native. Native class hints are not catalog identity proofs. Locale/search/NoDisplay policy has not been expanded.

The pure Elm decoder rejects unknown fields, duplicate IDs, malformed/lossy counters and excessive text/counts. Intents refer to an admitted entry ID and authority lifetime/generation using decimal strings. Native snapshots fingerprint both original source bytes/file identity and complete parsed metadata. Source changes retire stale intents even when the visible name is unchanged. The prototype admits at most 2048 records and one MiB of compact ASCII-escaped JSON; overcapacity retires availability and refuses the whole projection rather than truncating it. Production broker framing budgets remain to be qualified.

Native default launch loads the original filename through GioUnix.DesktopAppInfo, revalidates its fingerprint before submission and submits through the owned GIO object. No display text is executed as a shell command. [GIO launch documentation](https://docs.gtk.org/gio/method.AppInfo.launch.html) distinguishes successful submission from subsequent application startup. The receipt therefore says Submitted, never Ready. Exceptions/false submission preserve Unknown and exact retries return the original journal receipt without another attempt. Retired lifetimes, reused/old request numbers, unavailable catalogs and stale/removed entries are refused. Returned journal records are copies so callers cannot mutate deduplication state.

Accepted evidence: 24 legacy parser tests, 23 compiled Elm decoder/intent checks, 22 isolated native checks including a real GIO launch to an owned argv recorder, and eight explicitly selected Quint runs plus 1000 invariant samples of 40 steps. The argv receipt proves literal spaces/$HOME, percent/name/icon expansion and the original desktop filename. No application readiness, GUI launch, native Unknown injection or full Quint-to-implementation refinement is claimed. Earlier reports and the initial model syntax failure remain preserved.
