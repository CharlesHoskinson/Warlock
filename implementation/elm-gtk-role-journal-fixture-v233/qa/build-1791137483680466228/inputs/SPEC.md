# Command and evidence contract

CLI --describe prints fixture contract without GTK initialization; --validate-command LINE parses one bounded command without display or side effects. --run uses only the selected owned private Wayland connection. Stdin is `SEQ COMMAND [A|C]`, positive canonical decimal SEQ<=INT64MAX strictly increasing per actor; replay/out-of-order/invalid/oversized lines refuse and exit nonzero, with local role cleanup. No retries. Commands are declared in requirements. EOF and quit close child/popover/nested roles before owner/independent roots and terminate0 if local cleanup succeeds. Controller consumes stdout and supplies overall deadline; flushing stdout is externally bounded.

Each JSON record has schema1, sequence (journal event order), pid, monotonicUs, requestSequence (last dispatched request), event, role instance/name/map generation when applicable. Role records distinguish toolkit requested modal/parent/group from actual mapped GDK class and wl_surface resourceID. GDK state updates are toolkit observations, not native compositor facts or exact protocol ACK. Map/unmap/draw callbacks are local lifecycle/queued rendering, never frame presentation receipts. Input records use raw GdkEvent source surface ID, actual surface-local position when available, widget-local coordinates and native surface transform separately. Pointer is GTK button-number domain, keys GTK/GDK keyval/keycode/modifier domain; they are not raw Linux evdev button IDs.

Raw stderr WAYLAND_DEBUG client journal and owning native scene facts must independently prove xdg_dialog_v1 modal and exact xdg_toplevel parent/popup relationships; absence/refusal is a failure to qualify that role, not a reason to label a toolkit modal as native. Root must bind role title, PID/start/native incarnation/GDK surface ID and actual scene ownership, and inspect normal server census after local exit. Native root/minimize/MAX/restore or popup/mixed input acceptance requires a separate reviewed serialized campaign, preserving original deadlines and exact receipt barriers.
