# GTK4 structured role fixture

CPU prototype only. No GTK display was opened, and no native modal, input, popup grab, screenshot or geometry operation has been accepted by this component.

Launch the selected built `gtk-role-client` only through the protected native runner. `--run` uses explicit A/B/D family and separate C WindowGroups. `--run-default-group` makes no explicit group; toolkit application-modal consumption must be evaluated separately from compositor policy. Both require `ELM_GTK_ROLE_QA=1`, `GDK_BACKEND=wayland`, `WAYLAND_DEBUG=client`, owning QA scope/core limits, and an owned direct `/run/user/UID/wqa/NAME` runtime with an owned nonsymlink Wayland socket. The runner must additionally prove exact compositor socket peer PID/start and owning modules/libraries, register the client Popen/logs, bound stdout, and prove empty native census on retirement.

Input is a newline-terminated positive canonical int64 sequence, a closed command and optional A/C target. Commands: create-owners; create-family (owners plus B); open-modal; close-modal (D then B); close-owner (P,D,B,A, leaves C); open-nested; close-nested; open-popover; close-popover; inspect; minimize/restore/maximize/unmaximize A|C; quit. `create-owners` cannot re-create an existing owner or independent C; D and P recreation receive new instance identities. Owner close requests retire only that family. Entry initial text is `ELM-ROLE-DRAFT`, maximum256 characters; journals record actual UTF-8 bytes and lengths. Root's native keyboard fixture decides whether typed content matches the intended sequence.

Journal JSONL records PID/processStarted, monotonicUs, event and request sequence, selected profile, object instance/mapGeneration, actual Wayland surface resource ID and class, GDK state, requested modal/transient and actual GTK group properties. Event source coordinates/type/time/button/key/modifiers are raw GdkEvent observations, distinct from controller-local positions and native transforms. Surface map/draw and state are client observations, not server ACK or physical presentation. Raw Wayland stderr and native role observer are required to join actual xdg_dialog modal state, transient relations and popup parents/grabs; there are no synthetic protocol receipts here.

Role drawing areas paint a solid role color and a yellow8x8 marker at local[4,4]; actual draw/native bounds and native surface transform are recorded without assuming their sign or placement. Popover button has actual native bounds and emits popover-button-clicked before local retirement. A and C backgrounds are red and green; B blue; D gray. GTK chrome, allocation and nonzero geometry must be measured, never inferred from preferred320x180 size. Current native nonzero GTK maximize can remain explicitly unsupported; do not force an origin to zero or enable capabilities to obtain a pass.

CPU tests execute the real compiled CLI and actual commands.h contract table, plus compiled unsafe parser controls. Callback tests compile actual extracted controller/surface/close functions with mock GTK objects, proving guards/disconnection, not GTK server lifetimes or real input delivery. The first callback-test mutant compilation failure is retained before the corrected harness. Actual build captures headers, system toolkit libraries/tools and source inputs; no installed files or frozen predecessors changed.

Normalexit means local destruction and clean client exit only. The runner must independently prove server resource/role retirement before plugin unload. Full GTK3 compatibility, default-group adversarial behavior, physical input modality, popup grabs, MAX/restore, draft preservation, held input retirement and G01–G12 remain native qualification work under the broader V234 plan.
