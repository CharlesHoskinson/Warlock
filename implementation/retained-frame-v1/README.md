# Retained native client frame prototype

Uninstalled QML component for Qt 6.11 / Quickshell 0.3.1. Caller explicitly supplies `source` (Wayland Toplevel), `sourceIdentity` (`stableId:pid:generation`), `generation`, then calls `acquire()`. No top-level popup, window focus, minimize action or compositor load is included. `snapshotReady` indicates offscreen snapshot update completion, not presentation. Source changes and generation/size changes retire the snapshot. A null source after a successful snapshot leaves that snapshot retained; caller must advance identity/generation on logical window retirement.

Native capture is still full resolution and may double-buffer; maxNativePixels refuses retention after source size becomes known, not before the compositor allocates its first frame. 300×180 snapshot default is 216,000 RGBA bytes nominal; real driver allocation/overhead is unknown. ShaderEffectSource adds a bounded offscreen copy intentionally to provide independent lifetime, not a claimed performance improvement. Host must limit the number of component instances. This version supports one snapshot and releases its Loader on reset.

The bounded proof requires serial private native QA: visible capture, source stop, source destruction, identity replacement, scale/output changes and measured allocations. Stock ScreencopyView clears content when capture context ends. Whether the frozen ShaderEffectSource survives source-context stop on the target renderer remains unverified; do not deploy or claim accepted hidden-window capture. Excludes server titlebars/borders/rounding and out-of-base popup family fidelity. No full-resolution animation source or decorated motion replacement is implemented.
