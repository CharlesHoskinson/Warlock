# Warlock shared generated backdrop provider

See [HANDOFF.md](HANDOFF.md) for the actual component evidence and remaining native gates. This is the full GUI519-derived Main/Bar/Popup provider with an additive explicit generated native backdrop source and FD4 physical ownership. The original transparent family path and one immutable Elm policy remain.

Build and model checks run through the protected launcher; native QA runs through the serialized build-loop wrapper on the exact owning ABI tuple. This component is not a completed release.
