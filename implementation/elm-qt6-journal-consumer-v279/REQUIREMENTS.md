# Qt6 journal consumer boundary

Consume actual held250 journal schema with exact process PID/start, consecutive
sequence, monotonic request/time, immutable previously observed prefix, bounded
UTF8/JSON primitives and the exact window-modal/application-modal profile. Reject
duplicates, nonfinite values, foreign lifetimes, refusal, malformed fields and
all observed prefix replacement. Incomplete trailing bytes are not complete rows.

Raw QWindow input and QWidget propagation are different events. A complete raw
pointer interval includes all QWindow press/release/double-click rows regardless
of trackedRecipient or role; a complete raw key interval includes all QWindow key
rows. Match exactly the expected current role/instance/map/resource and actual Qt
event type, source resource, key/button domains, modifiers and positions. Never
select only favorable role rows. Unsupported double-click expectations refuse.

QWidget rows may multiply as events propagate. Do not count them as new native
dispatches or collapse them into one raw QWindow receipt. Native modal eligibility,
server focus, raw Wayland joins, window retirement, pixels, parent transforms and
toolkit action callbacks require separate proofs; parsing journals is not native
acceptance. Actual Qt enum constants must come from the owning compiled header.
