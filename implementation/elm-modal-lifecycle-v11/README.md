# Modal held-input lifetime qualification

Fresh derivative of V9's accepted fixture on the same frozen V10 native tuple.
All original 19 identities remain. Four new checks hold one actual virtual pointer
incarnation across a blocked-parent press, modal retirement and release over an
independent peer. The press selects the modal; closing the modal before release
does not deliver either press or release to the independent peer. The held-pointer
helper exits normally, and a fresh pointer click plus actual keyboard event reaches
the peer after retirement.

`qa/native-1791056554713775783/report.json`: 23 checks passed, protected private
scope, clients/plugins before compositors, cleanup passed. `qa/slice-manifest.json`
checks the original V10 core/source manifest and every accepted packet artifact.

The helper uses a private 0600 FIFO under the private fixture output. It is owned
and registered by the private host; an explicit writer controls its lifetime and
closes before waiting on normal exit. No user's physical pointer or desktop is
used. No new core or plugin is loaded without the exact V10 frozen closure.

This is one native retirement interleaving, not complete device-incarnation,
exclusive-layer, session lock, nested-modal, ambiguity or resource-bound coverage.
