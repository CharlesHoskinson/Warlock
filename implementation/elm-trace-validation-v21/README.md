# Diagnostic trace validation

V21 is a fresh derivative of V20 for hardening the typed Elm diagnostic decoder
and its refusal tests. The native core/plugin pair and historical native evidence
remain V20. This slice does not change compositor policy or admit a canonical
scene. A usable dispatch trace is still diagnostic; monitor commit is not
presentation feedback, and a surface input region alone is not a complete native
hit-test eligibility decision.

The compiled decoder passed 121 checks, including all 18 historical V20 native
packets, positive boundaries and negative mutations for geometry, alpha, identity,
protocol and capacity combinations. Oversized arrays are refused before decoding
elements; the incoming JSON value itself is already allocated by the host.
Retained frames remain historical. Canonical scene, current-scene evidence,
correlation and presentation evidence remain explicitly false. Exact source and
compiled replay hashes are frozen in `qa/slice-manifest.json`.

V20 historical evidence, not rerun by this documentation work:

- Ordinary private native regression: 63 checks, cleanup passed, in
  `../elm-surface-facts-v20/qa/native-1791066204888892063/report.json`.
- Continuous full-redraw diagnostic: 84 checks, cleanup passed, in
  `../elm-surface-facts-v20/qa/native-1791066071820282438/report.json`.
  The bounded findings include immutable retained geometry after resize, a fresh
  resized draw with stable surface identity, output configuration capture, and
  retained/fresh identity behavior through unmap/remap. The configuration provides
  no production performance or power qualification.
- Compiled Elm: 28 checks, including 18 actual native packets and eight malformed
  packets, in `../elm-surface-facts-v20/qa/elm-1791066169040465004/report.json`.
- Quint: six explicitly selected named cases and 1,000 invariant samples at
  40 steps, in `../elm-surface-facts-v20/qa/model-1791066125815354429/report.json`.
  This is abstract capture/history immutability evidence, not native refinement.

These reports do not complete S06 or any entire roadmap requirement. All original
evidence and failed attempts must remain unchanged. Nothing in this slice is
installed on the user's desktop.

The next native slice should qualify surface-to-output mapping and input masks:
use an owned overlapping-window fixture with an explicit input-region hole,
capture the visible pixels and recorded masks, then exercise actual pointer and
keyboard delivery inside and outside the hole. Add an output configuration change
to prove that retained facts stay unchanged while fresh dispatch facts receive
the correct configuration generation. Native campaigns remain serial through
the protected launcher with exact core/plugin ABI pairing and original deadlines.

That work contributes to `ELM-GNO-006 hit-region-hole` and scene coherence; it does
not qualify all roles, transforms, devices, buffer/clip mapping or presentation.
After admitted scene dependencies and native paint/input agreement are established,
the next product slice is an integrated Elm taskbar with selection and
minimize/restore, followed by Alt-Tab switcher lifecycle. Retained previews,
animations, launcher, Task View, snapping, accessibility and release recovery
remain later acceptance work in the existing roadmap.
