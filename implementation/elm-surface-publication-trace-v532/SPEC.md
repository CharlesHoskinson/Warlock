# QA publication and input tracing

This derivative copies521 byte-exact except two qa_exit-guarded native logging blocks. Capture parsed controller view-commit packets and surface-context messages at their existing receive point; record actual GTK button/proof metadata after existing event state updates. No new message, admission decision, callback, effect, proof stamp or deadline is introduced. Logs are confined to controlled QA mode. Logging changes observation overhead, so trace runs are diagnostic and cannot substitute for uninstrumented performance or causal native refinement.

Trace must correlate owning view/generation, full frame identity, native proof publication/lease/epoch, actual right-button press/release, received context stamps, admission result and original deadline. Inspection-body equality alone is insufficient evidence of full frame equality. Keep failed504 and all accepted packets unchanged.
