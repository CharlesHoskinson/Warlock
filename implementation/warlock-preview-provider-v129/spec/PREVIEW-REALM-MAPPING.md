The preview realm model specifies CONTROL-020. It supplements the original
capture/resource/retirement models and does not replace Elm policy or any
physical ownership oracle. Sixteen named scenarios are selected explicitly.

The compiled replay invokes the actual controlled C factory and dispatcher,
original authenticated synthetic Native socket, Endpoint/Broker, original
permanent-incarnation retirement observation, final processing journal,
independent confirmation and strict C close. Each event compares native active
claim, actual receiver grant epoch, actual job/actor/proof counts, terminal
state, C empty predicate and operation success/refusal. Native binding equality
is checked after every event. No state comparison is inferred from a requested
event. `phase` and `through` are protocol-history ghosts excluded from actual
comparison; failed constructor epoch consumption is observed in the next actual
grant. Owned teardown occurs after comparisons and must exit normally.

Open, source-refused construction, concurrent admission, legacy admission,
reconciliation, polling, final job acknowledgment, native actor retirement,
final actor processing, independent confirmation and strict close map directly
to their actual C/Native APIs. OldTicket replays the exact ticket retained from
the previously closed owner against the new owner on the unchanged Native
binding. Refusal must occur before the new job is quarantined or settled.

Three independently compiled unsafe derivatives remove persistent receiver
epochs, allow controlled-to-legacy downgrade, or release a claim before strict
close validation. They must differ at a selected trace's original observations;
a sanitizer crash is not a behavior witness. The separate C witness tests the
last uint64 epoch and exhaustion using a fresh counter-initialization derivative.

This model starts with one unattempted metadata job. It does not qualify captured
pixels, reader drain or allocation failure; existing actual SCM_RIGHTS/GIO and
post-adoption allocation witnesses retain those independent obligations. Its
actor route still requires permanent native incarnation retirement. Live-window
binding detachment, bootstrap reattachment, frontend realm event scoping,
WebKit activation and actual Core qualification remain open. Neither the model
nor compiled replay establishes native GUI or full release acceptance.
