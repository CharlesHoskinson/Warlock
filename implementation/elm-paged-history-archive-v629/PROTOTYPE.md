# Symbolic prototype bounds and evidence

`archive.qnt` is a pure typed transition model of immutable fact conservation, durable root publication and bounded hot state. Keys1..8 symbolize exact complete origins; `key*10+kind` symbolizes the full immutable envelope and independent event kind. Tags0..5 denote Admission, Unknown, terminal receipt, Prepared proof/join, Released and delivery certificate. This encoding is not a hash/key/wire parser and does not prove exact JSON bytes. The symbolic migration imports old terminal evidence10/12. A conserved ghost set detects erasure across root replacement/compaction. Watermarks use one symbolic monotonically increasing ID; real independent request/generation/proof domains require separate indexed implementation tests.

A staged transaction has at most two facts and hot state at most two keys. The archive can accumulate more historical facts than the hot bound, up to the configured symbolic disk quota24; this demonstrates separation of queue/history bounds, not unbounded proof or real64-entry performance. Actual page sizing, persistent B+tree/cache, quota reservation, ownership/hardlinks/symlinks/locks, concurrency, hashes, corrupted bytes, per-record certificate generations and physical disk errors are design obligations outside the model. The boolean `locked` only establishes authorization ordering sensitivity. `LateC` abstracts synchronized suppression of an exact archived release and retention of a different key; actual late-writer detection, native grant authorization and filesystem cleanup remain mandatory.

WritePages→SyncPages→SyncPageDir→WriteManifest→SyncManifest→Publish→RootSync represents the success barriers of a bounded append/root transaction. ProcessCrash preserves namespace publication and clears root readiness; PowerLoss restores the durable root/files. RestartSync may commit a surviving valid published root, but unpublished staged metadata must not activate migration or admission. Prepared commit precedes exact unlink/admission-directory sync; Released commit precedes ACK/delivery. A final Released record does not manufacture terminal truth: its original Unknown event remains reachable.

The first sampled campaign found a genuine model defect: Migrate set candidate migration/mark metadata before Publish, and RestartSync could activate it with an empty archive. The complete failed source and sampled counterexample are retained under `qa/failed-migration-restart`. The corrected reducer sets candidate migration metadata at Publish; `stagedMigrationRestartCannotActivateTest` rejects prepublication activation. The initial reserved-name parser error and mutant-selector error are also retained, without counting them as valid negative controls.

`qa/accepted-before-boundary-extension` preserves the successful18-case intermediate. The final model adds14 exact process-crash/power-loss scenarios at each of the seven publication barriers. Every named case is selected by exact identity; execution names must equal selections. The final protected campaign and `qa/report.json` capture32 names, commands, Quint version, seeds, hashes, accepted ITF traces,1,500 sampled traces/max70 transitions and10 typed negative controls. Mutation assertions detect early effect, surviving unsynced power-loss namespace, skipped page durability, compaction erasure, hot overflow, quota bypass, exact-key resurrection, missing restart barrier, missing admission absence fsync and unanchored certificates.

No native, actual filesystem-store, paired C or integrated GUI experiment ran. Original V608/V624 source is retained under qa/ancestry and verified unchanged during freeze. Full S15 is unaccepted until the implementation gates in ARCHITECTURE.md and OPENSPEC.md pass. The model does not authorize removal of predecessor bytes or historical64 constraints.
