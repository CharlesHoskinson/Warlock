# Warlock full preview provider integration

Fresh full GUI519 derivative. The native URI endpoint owns the one physical Broker. The demand coordinator borrows it under the same mutex; native captures and URI readers share capacity, exact jobs, cleanup and request floors. `enableDemand` accepts a one-time trusted policy whose limits exactly match the actual Broker. It pins the native lifetime/clock and positive interval. The coordinator cannot be copied or moved away from its owning storage.

This is an integration prerequisite, not an installed provider. The actual host child grant/bootstrap, authenticated observation and Elm job/receipt conversion, production capture and original native acceptance remain open. Root-plane492 remains ineligible for client/family presentation. The full unchanged Elm policy and host surface routing are preserved; no second authoritative policy was introduced.

A stream close only drops its read reference. Cancellation and producer completion cannot erase consumer-held storage. The provider must prove producer and consumer completion, destroy physical storage and retain final receipts until exact acknowledgement.
