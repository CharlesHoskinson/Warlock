# Combined output and menu candidate

Fresh composition of frozen V4 visible menus and accepted V118/V119 monitor
ownership/popup dimensions. Original parents and failed evidence remain unchanged.
This source runs one controller and one immutable GdkMonitor owner per process.
The host registers process-local output/provider IDs through a dedicated owner
port before starting its native backend; these IDs are separate from effect
output generation. Conflicting registration retires menu presentation permanently
without discarding forwarded receipt mappings.

Menu cancellation waits for matching fresh native facts before returning focus to
a surviving group opener. Dispatch closes the popup and forwards one intent in
the same atomic commit, without a cancellation focus refresh. Native key replay
suppression, receipt correlations, resource bounds, popup leases, V118 padding and
logical geometry clamps are retained.

Protected compiled QA includes 64 menu/controller checks, preserved 20 replay,
27 Shell and 55 surface checks, independent original 67 output-controller and 12
presenter checks, native host self-tests and 20 key-classifier checks. Native
results are separate and recorded only after actual campaigns finish. The
freezer checks all parent hashes, actual tested source/build closures, original
scenario AST/deadline/check identities, and normal cleanup.

From the repository root, native scenarios run serially:

```bash
python3 -B implementation/elm-menu-output-v5/qa/run_native.py native
python3 -B implementation/elm-menu-output-v5/qa/run_native.py regression
python3 -B implementation/elm-menu-output-v5/qa/run_native.py output-regression
```

The wrapper invokes the global coordinator and unchanged protected launcher.
Native experiments use private desktop instances and leave the main desktop alone.
One immutable owner per host and separate fixture hosts do not qualify a shared
controller across outputs. Bar keyboard ownership, exhaustive gesture sequences,
active output resizing, accessibility/IME, full menu providers, all-origin unknown
operations, lost-broker recovery, hardware budgets and release journeys remain
open. Earlier component Quint proofs do not establish equivalence of this merge.
