# Qualification limits

V5 combines reviewed source behaviors on an isolated owning core/plugin pair.
Native campaign acceptance requires all original oracles and normal teardown.
No mandatory requirement, complete feature or release is marked accepted here.
Native callback owner metadata is a trusted process-local transport contract;
it is not an independent identity or authentication system. Physical monitor
retirement terminates the host; pending journal recovery after exit is unqualified.
Menu ID/lease refresh, disabled actions, command allocation and late receipt
mapping are independent from authoritative state refresh and opener DOM focus.
DOM focus alone does not grant the bar native keyboard ownership.

Current provider registers only the native window actions supported by the owning
engine. Application, Files, background and settings menus require their own typed
providers and policy. Popup-origin and keyboard placement still use the fallback
anchor. Live same-monitor geometry/scale changes and the global output registry
must be integrated with the concurrent output lane before release acceptance.
