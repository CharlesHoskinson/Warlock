# Controlled-client journal validation

A CPU-tested native QA prerequisite, not native evidence. Parse complete bounded JSONL (2MiB,8192 events,8KiB per event), reject duplicate keys/nonfinite numbers/truncated lines and wrong PID. Require consecutive event sequences, nondecreasing positive monotonic time and exact common field types/ranges. Configure→ACK→buffercommit must preserve serial/dimensions with distinct records. Validate profile origin/padding/scale and geometry/surface/buffer extents, declared resource bounds and ready identity. A final normalexit is required only for terminal snapshots. Accept serial wrap/reuse via ordered configure generations instead of imposing global serial uniqueness. Synthetic tests explicitly remain synthetic; only a later actual private client capture supplies native evidence.
