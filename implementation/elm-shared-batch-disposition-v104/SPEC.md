# Exact batch disposition prototype

This fresh derivative verifies all 2,059 entries in V308's frozen slice inventory before copying final V305 production source. Ancestors, primary lanes, native deadlines and failed evidence remain unchanged. It is an imperative Elm/C prototype; it adds no Quint logic or GUI acceptance.

The host returns a typed disposition from the actual inner surface_receive: ignored, preflight-unsent, admitted or uncertain. Its actual lease/publication/whole-batch preflight remains unchanged. Preflight-unsent returns before journal admission or forwarding. Admission failure and popup-open failure after admission return uncertain. No refusal diagnostic or view-commit log is interpreted as an acknowledgement.

Only the authenticated primary controller manager submits view-commit. The shared wrapper preserves the literal original bridge JSON.stringify text alongside parsed source, across conversion to the inner surface protocol. The bounded certificate has exactly these keys: viewProtocol=1, kind=batch-disposition, disposition (preflight-unsent/admitted/uncertain), scope{id,generation}, revision (topology), publication, lease, binding and batch (the literal original full envelope string). It includes the entire ordered requests, frame and focus through that original envelope. Native requires a live positive view, current authority binding matching every request, at most16 requests, request wire at most4096 bytes and original envelope at most131072 bytes. It captures scope, revision and binding before synchronous popup/native mutation and validates the captured live scope/revision again after return. It never dereferences a captured OutputView pointer after that call.

Main calls OutputController.register before emitting the outgoing port. A registered record holds exact live scope, topology revision, publication, lease, full native binding, literal outgoing envelope and observation correlations. The registry holds at most16 unacknowledged records. The envelope bound uses actual UTF8 byte count after a short UTF16 length gate. At capacity or absent live scope, authority transport is refused conservatively without evicting records or declaring any operation completed. Permitted empty presentation packets do not claim authority forwarding. QA separates attempted effect wires from requests in an actually submitted packet.

A strict disposition consumes an exact record once. Wrong fields, counters, view generation, topology revision, binding, publication, lease, disposition or any changed envelope/request cannot consume it. Admission and uncertainty retire only transport tracking. Neither proves an unsent operation or read. For exact preflight-unsent observations under the same native binding and lease, the controller reconciles logical popup dismissal, cancels a prepared selection if present, clears only still-matching observation slots and allocates fresh read IDs. Pending effects defer reissue and keep the dirty bit. Old observation responses cannot satisfy new slots. No operation is replayed or assigned a fabricated native receipt. Existing issued keys, Effects unresolved entries and Menu receipt-router entries survive; the CPU oracle delivers an exact original actor B definitive receipt after unrelated actor A recovery.

# Explicitly incomplete boundaries

Authoritative topology retirement currently drops old transport records while retaining possibly-sent observation expectations. A pre-owner registration refusal also conservatively exhausts transport. These availability paths need the separately authorized fresh topology/read-supersession correction; this prototype is not the final remedy.

Unsent operation-only and mixed-batch effect records remain Pending/Unknown until a distinct valid terminal/recovery path exists. Journal-admitted or uncertain operation recovery continues to rely on existing schema5 machinery; this packet does not qualify storage-write failure or popup failure recovery. Generic catalog/launch, cross-binding and reconnect traffic is not covered by the window observation recovery oracle. In particular registration's whole-envelope bound does not add a per-request4096-byte gate; native declines a certificate for oversized requests. Do not claim recovery for oversized non-window traffic.

A malformed/retired topology envelope rejected before a recoverable source scope exists cannot obtain this certificate. Certificates are not generic permission to retry effects. Shared native right-click/focus integration, target-retirement scenario10, one combined current core/plugin/AQ tuple, all original absolute deadlines, full operation recovery and release remain open.

Independent review also identified a pre-hold stale-certificate UI defect: exact old batch records can trigger NativeDismiss/prepared cancellation before Shell rejects their obsolete observation IDs. A fresh correction must validate current observation slots before any UI side effect. This defect is preserved here; current passing scenarios do not qualify that stale-query-completion path.
