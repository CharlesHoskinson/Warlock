# Reachable-axis characterization requirements

This CPU experiment characterizes the actual paired Hyprutils CBox rounding and the zero-origin owning MAX/ordinary conversion. It grants no native capability, production policy, approved formal transition logic or release acceptance.

- RA-001: Compile against the actual owning Hyprutils headers/library and verify their hashes against pair90. Preserve exact original WindowTarget ordinary/MAX and Target rounding source identities from V155/V166.
- RA-002: Enumerate bounded target inputs through actual CBox.round(), then MAX selects the rounded nonempty visual box or logical box, subtracting fixed top-left plus bottom-right reservations exactly once. Ordinary restore uses the rounded logical box without MAX reservation subtraction. Configure dimensions are floor(real) on both axes.
- RA-003: Validate finite nonnegative reservations and finite positive supported boxes; collect distinct reachable positive configure integers satisfying independent raw-configure and layout-real bounds. Do not intersect different spaces or substitute abstract arithmetic for the actual conversion oracle.
- RA-004: Preserve externally specified witnesses: zero-reserve layout128.9..129.1 reaches only configure129; layout129..131 reaches129,130,131; reserve1.25 with rounded targets130,131 reaches128 and129; ordinary restore ignores MAX reservation; horizontal/vertical cases agree under swapped input. Raw upper129 admits real129.75/configure129; raw lower129 rejects configure128 even if real128.75. Tiny maxima1 and2 have different reachable cardinality.
- RA-005: Characterize fractional origin edge-aware rounding, visual-versus-logical choice, asymmetric reservations, noninteger layout bounds, invalid/fixed sources and numeric boundary/cancellation cases. Preserve unsupported/nonzero-origin/invalid values as explicit refusal or scope exclusions; do not invent a conversion.
- RA-006: Propose an exact reachable-domain definition in terms of the actual double conversion and bounded integer rounded target, separating a real-arithmetic closed form from IEEE/native equivalence. Finite sampled enumeration is not proof over every double/int/native arrangement.
- RA-007: Preserve compile/runtime failures and unsafe controls. Capture runner/source/header/library/tool/compiler dependency identities, exact generated source, logs and binary. Freeze only after protected CPU success and source recheck. No GUI or native frames.
