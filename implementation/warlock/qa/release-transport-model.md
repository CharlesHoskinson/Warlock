# Release transport identity: bounded model and correspondence

ELM-DEL-005 / delivery-005 requires all shipped components and applicable notices to be accounted for. This model addresses only transport identity supporting that oracle; it does not assess the SBOM, license authority, actual notices or release acceptance.

Source snapshot (SHA-256 at this check): `adapter/release_compliance.py` 51f7557b4a741106f3b7ffc16df09ae86aa90ca580578ea40a1ff175d4a48964; `adapter/release_builder.py` 640b47a214286ca9ec3fcda74d98d895610202befd49e9b8bcce51706e9a9919. `_path` validates relative spelling, `_inside` checks resolution, and `_inventory` uses lstat/readlink and rejects escaping or non-file targets. `package_compliance` (lines 358–403) produces an immutable receipt of reviewed premetadata inventory and generated metadata digests. `audit_archive` (lines 406–455) inventories containment, requires a receipt when compliance metadata exists, compares reviewed identities and metadata digests, then compares archive member names (including duplicates), types, link spellings, file hashes and live payload/manifest. `build` passes that receipt and performs input verification after audit (lines 528–553). Recheck hashes before relying on correspondence.

`release_transport` represents one symbolic file/link class and two required member names, with duplicate names retained in a list. Opaque integers distinguish canonical target, link spelling, content and type; version fields distinguish manifest/archive identity. Independent actions mutate link spelling, canonical target, escape status, member list, type or content, and restore; refreshAlias represents a newly matching manifest/archive alias. Audit records its decision and separate observation fields. The safety invariant describes the identity captured by an accepted decision, not the mutable filesystem forever after that decision. The model's audit combines the *desired* containment and archive checks; it is not a literal translation of `audit_archive` alone. Each action is an atomic abstraction; real traversal and audit consist of multiple operations and may interleave with external changes. In particular, the model does not demonstrate that the production sequence pins or revalidates its reviewed inventory.

Assumptions and omissions: hashes are opaque identity classes, not a cryptographic proof; modeled audit observes a consistent snapshot and cannot prove OS resolution, permissions, concurrent read atomicity, symlink race resistance, legal provenance, or native desktop correctness. A sampled model pass is not implementation proof. Exact historical native artifacts and compiler/source/project-grant provenance remain missing from release acceptance.
