The taskbar reserves eight CSS pixels around the scaled row and the native host reserves the same band (56 pixels at 100%, 80 at 150%, 104 at 200%). Horizontal reveal includes the outline extent. Controls retain the enlarged two-line group caption; popup controls reserve contour space.

Original scenarios remain ELM-UI-013 `readability-high contrast` and ELM-UX-027 `ux-027`, with their original oracles. WARLOCK-DL-006 supplies the adopted outer, minimum two-pixel, 3:1 contrast contract. This is a presentation change, with the existing Elm/native effect and focus authority preserved.

The final protected build compiles all current roots and native host, runs existing Settings/TaskView/focus Quint named tests and sampled safety checks, and passes 102 browser checks. Its 64 first/last taskbar observations cover night/dawn/high contrast, 100%/200% text, 320/800 widths, effects on/off and high-contrast forced colors. The Active two-window caption is a supplied readonly layout fixture; it does not qualify actual native grouping. Each full label/detail box, target and outer contour must fit. Minimum observed target height is 46 CSS pixels. Actual native taskbar group semantics are covered separately by the prior group-state evidence.
