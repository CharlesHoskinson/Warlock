# Stable observed Always on top

ELM-UX-016 / original `ux-016`: displayed pin/MAX state must agree with native state and the visible hit target. The original statement and verification remain in `manifest.json`; this packet is partial, with independent acceptance and broader release obligations open.

The shipped provider keeps **Always on top** across pin/unpin. The root derives its optional typed `checked` presentation flag from the exact current menu/provider native geometry observation, rather than a desired action or a Committed receipt. The current renderer exposes one visible check shape and `menuitemcheckbox`/`aria-checked`. Legacy controls remain admitted; checked controls require the current strict shape, menu scope and menu identity, with a boolean value and at most one checkbox. The flag grants no action authority. Application taskbar Pin/Unpin vocabulary is unchanged.

MAX selection details include committed state before `Selected`. The renderer now exposes that selection through `aria-current`, and passive resize/reveal observers cannot consume a selection change before the selecting observer moves keyboard focus. Enter keeps the existing native menu navigation proof route. Current captured identity, readiness, prepared correlated reads, repeated-request rejection and Unknown/no-replay gates remain authoritative.

All original native surface tests plus focus/checkbox shape and no-action-authority negatives pass.
- Twenty-one browser checks cover one stable label/keyed node and actual DOM focus, checked AX semantics, MAX `aria-current`, malformed scope/shape fail-closed withdrawal and fresh recovery, original Enter proof routing, one pointer action, disabled no replay and high-contrast checkbox shape. Browser pages use the shipped UTF-8 encoding. Browser AT is not native speech or braille.
- The original protected native UX-016 pointer maximize/pin/unpin journey passes with preserved MAX geometry, exact shared intents and three physical captures whose painted overlap agrees with real GTK press and focus recipients. Two extra physical Tab/Home/Down/Enter toggle journeys focus the actual selected checkbox, invoke once each and preserve MAX geometry. The complete native report has 81 passing checks and normal cleanup; main desktop and owning core/plugin ABI are unchanged. Checked and unchecked native menu captures are retained.
