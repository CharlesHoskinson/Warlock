All current grants, scope generations, size feasibility, native focus/peer preservation and Unknown/no-replay barriers remain unchanged.

The original native keyboard campaign now passes all nine migrated surfaces in its original order and deadlines. It physically selects the current family, snaps to the right half with a matching `Committed` receipt and actual `[400,48,400,552]` window geometry, activates a Task View member, dismisses it, and operates held-Alt switching. There are zero injected pointer events and owned cleanup passes. The earlier `snap-protocol` failure remains retained.

Actual compiled root, wire/custody validators, snap/menu keyboard browser and owning native ABI build pass separately. The model abstracts protocol versions; its sampled results do not establish native negotiation.
