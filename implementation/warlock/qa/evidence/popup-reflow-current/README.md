# Enlarged active popup resize

The ready picker and operation menu now retain the exact Elm selection/policy
when native output locations change without changing any view capability.
OutputController updates routing locations and the topology revision using the
native host's existing topology-only publication path. Its full retirement and
observation reconciliation path remains for changed view identities/generations,
unready state, registration refusal and exhausted batches. Native effect
eligibility still belongs to the existing native authority.

Picker cards adapt to the available viewport height at 200% text. The old target
was 254 pixels tall in a 252-pixel popup; the small target is now 222 pixels, with
the original font and readable captions retained. Fresh-lease presentation
reveals only the actual current focused eligible DOM control after native
focus/layout settles. Same-lease observations preserve deliberate scrolling;
an old remembered identity cannot restore focus when the current control is lost.

Original ELM-UI-008 `overflow-resize` retains its exact oracle: **identity and
configured order persist with reachable active selection**. The actual native
200% campaign uses 18 overflowing pins and ten window roots, starts on 480x360,
grows to 640x480 and shrinks back for both the selected picker member and the
selected operation. It passes 176 checks and normal owned-helper cleanup, with
unchanged pin/control order, selected identity, complete target containment,
readable label pixels, old-input closure and fresh popup leases. It reaches all
ten members, opens first/last menus through secondary click, Menu and Shift-F10,
traverses operation and snapping/dismissal controls with real keys, returns to
the appropriate application or toolbar, activates the exact final member once
with a native committed receipt, and delivers actual keyboard input to that GTK
window. Eleven unique control captures and the selected-window capture retain
their original hashes. The standard native Activate/Minimize/Restore keyboard
regression also passes 131 checks with real recipients/pixels and normal cleanup.

quint-llm-kit modeling preceded the routing code. One reducer observes native
geometry/topology and exact popup callbacks; native resize seals input first,
unchanged location supplies no new grant, and changed generation retires the old
owner. The model uses one cohesive record and guarded pure transitions. Eight
named checks and 1,000 sampled safety traces pass; grow/reflow, grow/shrink,
replacement-retirement and refusal witnesses are reached. This abstraction
covers output routing and presentation leases, not native scene validation,
transport, custody, actual pixels, AT or UInt64 counter exhaustion. The compiled
production reducer/full-output integration passes 21 checks, retaining all ten
original reflow checks and adding same-scope and genuine-generation-change cases.
The original focus model remains unchanged. The browser suite passes 50 checks,
including the original 45, small enlarged-card geometry and exact retained DOM
focus through a fresh lease with ordinary-scroll/old-selection negatives.

Retained failures explain the delta. A coarse wheel step skipped the group's
actual hit intersection; its bounded physical step now reaches that group. The
small card was too tall. Location topology then withdrew registration and
discarded the picker before reflow. A full-root compiled replay retains this
counterexample; a separate late-reveal run shows the retained focused control
outside the grown viewport. The old native fixture also assumed pointer-menu
Escape acquires toolbar focus and Tab skips the already-shipped snapping control.
It now preserves the actual application recipient, establishes toolbar entry
through the real Super+Alt+Space shortcut, and traverses that enabled control.
Added browser lease cases required the later fixture leases to advance; failed
arrangements and every original assertion are retained. No manual native focus,
longer deadline, policy oracle rewrite, weaker pixel threshold, extra window
effect or relaxed native grant/custody rule was introduced.

The original scenario remains **partial**: applicable native AT navigation,
operation names, focus/speech/braille and independent original-scenario review
are still required. Broader provider/output/profile coverage and release-wide
hardware, resource, package and rollback gates remain separate. The earlier
native AT/WebKit reopening failure and IME candidate-popup failure are unresolved.
Model/component/native fixture passes do not accept the whole release.
