# Settings help

Settings offers optional keyboard navigation, preference and unconfirmed-action guidance. Dismiss help hides it for the host session; Show help reopens it, retaining the focused control. Closing/reopening Settings retains dismissal. Help preserves unsaved edits and pending/Unknown saves and emits no effect.

The actual compiled roots, 29 Settings replay checks and 38 browser checks pass. The protected native journey opens Settings, changes an unsaved theme, dismisses help, closes/reopens Settings, restores help, navigates and dismisses using only a real virtual keyboard. It observes zero pointer events, no preference writes or window actions, the focused painted Help control and normal owned cleanup.
