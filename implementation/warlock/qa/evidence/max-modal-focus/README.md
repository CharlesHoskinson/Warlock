# MAX modal activation

A qualifying ordinary MAX parent click now selects its native modal from the committed window order, revalidates the same scene, suppresses the press/release before focus callbacks and raises only the accepted modal. The shared selector also serves existing taskbar family activation. Ordinary pointer traversal continues to exclude modal-blocked parents. A selected modal with its own blocking child is refused; stale, ambiguous or ineligible selection does not send a lower-root click.
