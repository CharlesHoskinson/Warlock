# Passive preview descriptions

The window picker now exposes preview state and fidelity as a description on each named action control. Preview updates create no independent live region. Fallback says “Preview unavailable” once, real window titles remain visible, and source-state changes retain keyed focus and reserved target geometry. Ordinary Popup and the native visual receiver consume the same typed visual fact; hidden previews add no description relationship or unused wrapper.

## Observed results

- The actual compiled native visual receiver/renderer exports the expected Chromium AX description for Loading, Live, Historical, Unavailable, fallback, capacity, waiting, expired, conflict, exhausted and hidden states. All 53 component checks pass, including two real browser Tab presses, stable name/focus/geometry, inert decorative content, description-ID collision handling, foreign binding refusal, exact repeated projection and closed-picker retirement. This is browser component evidence.
- Original typed preview replay passes: source eligibility, fence/coverage, foreign incarnation, publication/lease invalidation, retirement and original four states. The unchanged `pickerOwnership` model typechecks and executes six named runs (one positive independent-family path and five negative/retirement paths), plus 100 sampled safety traces of up to 20 steps. The native key/ownership component passes. These are abstraction/component results, not GUI acceptance.
- The unchanged protected native picker journey passes 28 checks on the exact current compiled assets and owning core/plugin/host tuple. It paints its own family pixels as Live and Historical, observes Loading in native DOM, and shows Unavailable at the original expiry. The source/authority/pool and effect semantics are unchanged. Every registered helper/client exits normally; plugin unload and cleanup pass. `Live.png`, `Historical.png` and `Unavailable.png` are native captures.

The view-only implementation follows quint-llm-kit’s `quint-execute-spec` workflow against the existing ownership model, whose safety properties and native producer were preserved. Renderer descriptions are projections of `PreviewVisual`, not an announcement queue or lifecycle policy.
