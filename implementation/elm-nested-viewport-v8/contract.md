# Nested viewport candidate contract

This source-only derivative preserves V7 public headers and adds translation-unit private viewport resources. The parent must advertise wp_viewporter v1; absence prevents backend startup. Parent ACKed logical geometry is independent of the child mode/buffer pixel dimensions. Every buffer commit queues whole-buffer viewport destination and matching xdg window geometry before attachment/frame/commit. Buffer dimensions must still exactly match the selected child mode. test() and commit() share the same preflight; an explicit null buffer is refused, and bufferless metadata commits never advance the committed input mapping.

NestedPresentation.hpp is the production policy helper. Presentation maintains pending, ACKed and committed snapshots with monotonic uint64 generations. Zero configure dimensions preserve the previous client choice; negative dimensions permanently invalidate the output policy. Overflow fails closed. Staging fences pointer coordinates, presses and axes. Only a successfully queued matching-generation buffer commit establishes the new mapping. Idle configure work rechecks its captured ACK generation before and after synchronous listeners. Obsolete frame callbacks settle pacing but do not advertise current-frame presentation.

BalancedButtons admits at most 32 simultaneous pointer buttons. A physical release paired with an admitted press is delivered even while mapping is fenced or focus has moved; unpaired releases and new fenced presses are denied. Pointer normalization uses committed parent destination dimensions and retains AQ output identity. Keyboard input has no geometry mapping and retains the inherited policy; no keyboard, touch, relative-motion, tablet or multioutput qualification is asserted here.

Hardware cursor mapping is supported only for identity presentation. Nonidentity mapping hides the parent cursor and setCursor returns false for a buffer, so the consumer can select its software fallback. This does not assert that the current consumer has a working software fallback or that nonidentity cursor/hotspot raster behavior is accepted. Frame callbacks are pacing signals, not compositor pixel/display receipts.

Root owns build/QA/freeze. This directory has no native acceptance claim. The mandatory acceptance target remains the original parent 800x600 with a child 960x640 mapping and return to 800x600, without enlarging the parent or weakening deadlines.
