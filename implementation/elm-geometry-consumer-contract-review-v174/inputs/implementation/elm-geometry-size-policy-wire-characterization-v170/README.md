# Captured sizePolicy producer characterization

The protected CPU packet compiles immutable V406 build1791125085822287165 source: geometry-policy.inc verbatim, geometryNumber/geometryRect exact extracted bodies and the exact sizePolicy initializer from geometryFacts. It includes the real captured V402 ProspectiveGeometry header and actual Placement header and links the qualified Hyprutils library. Stub accessors supply already-converted layout/raw bounds, XDG origin, monitor scale, reserved extents and workspace area. Actual library dependency hashes and generated sources are retained.

Thirteen named cases emit JSON fragments, never authenticated native frames. They cover GTK108x42 with no layout maximum, version1 field omission, unavailable target/toplevel/monitor/workspace, fixed raw/layout axes, invalid negative/NaN bounds, unsupported nonzero origin, a layout-rule maximum wider than raw maximum and scale2 metadata. Thirty-one checks include capture/dependency validation and fragment assertions. No command, live role, conversion pipeline, native capability, callback/ACK/pixel or model qualification is performed.

The actual formatter emits an outer sizePolicy object even when inputs and both projections are null. This differs from SPEC.md's unavailable-conversion outer-null statement. A finite nonzero origin retains profile wayland-zero-origin-v1 and nonzero geometryOrigin in inputs although the actual project helper refuses both operations. Missing workspace retains inputs with no projections. These are observations of current bytes, not schema repairs; producer/consumer policy consistency remains open.

The unavailable-target sample calls the extracted formatter/functions directly. Full geometryFacts would throw Missing geometry target earlier and would not emit that native window row. Full geometryFacts ownership, eligibility, capabilities, bound iteration, revision fingerprint and negotiated envelope are not exercised by this harness. The ordinary restore sample supplies equal explicit saved logical/visual rectangles so the owning geometryProspective equality guard can pass; it does not prove native placement capture or other decoration/origin restore cases.

V406, V402 and formal V161 are unchanged. The report's success means the controlled producer characterization matches its actual output, not that the written schema, strict consumers, new geometry policy or native implementation is accepted.
