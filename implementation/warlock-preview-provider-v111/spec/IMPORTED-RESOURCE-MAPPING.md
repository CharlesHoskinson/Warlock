The initial model state follows one actual controlled C acquisition, real
authenticated SCM_RIGHTS transfer and adoption of its sealed 16-byte fixture
storage into the original Broker. The old export-release acknowledgement is
refused, although the fixture's actual export is already physically closed.
The resource protocol observes and settles that original backend obligation.
The fixture bytes establish mapping and reader ownership, not decoded pixels.

Each trace starts a fresh owned socket child. OpenReader/Read/CloseReader call
actual Endpoint/GIO methods. Reconcile proposes, dispatches and confirms the
canonical native purpose ticket; Poll invokes actual borrowed C retirement
polling. Ack dispatches the actual final terminal proof sequence. Close invokes
strict C close while the original window incarnation is still live. A completed
job cannot replace the distinct permanent-incarnation retirement fact.

Model producer/exported map to the child engine's actual owned-map count files;
mapped maps to the original imported kernel descriptor and its fcntl state;
reader maps to actual Endpoint reader count; known/terminal/proofs/bytes map to
Broker inspection and charge. Offset is the number of successful bytes actually
returned since the current reader opened. Last records read/open/close outcomes.
Captures and transfers map to actual child counters and must both remain one.
Quarantined is the history of successful original Reconcile dispatches; it is a
ghost used to predict observable permission denial, never product policy input.
Locked maps to the engine fixture's owned lock file. Lock is enabled after
quarantine; it tests backend retirement obligations, without claiming that the
synthetic source-scope reply implements the compositor's lock/privacy route.

Original uint64 Native bindings, capture requests, nonce, context, clock,
resource sequence and two-second deadline remain unmodified in actual traffic.
Their lossless decoding and monotonicity have separate capture/resource models;
this quotient fixes the original job and represents only local ownership
interleavings. Each trace is at most 40 steps with the original deterministic
native clock, within that deadline. It is not measured latency acceptance.

Teardown after compared states independently closes readers, unlocks, drains
through the real protocol, acknowledges actual terminal proof, obtains the
original permanent-incarnation fact and confirms final actor processing. Only
then may strict binding close and normal owned-child exit pass. Teardown does
not supply missing trace events or hide mismatching intermediate states.
Post-transfer allocation failure is a separate actual allocator-fault witness;
the normal adopted-reader model does not claim to model that failure prefix.
