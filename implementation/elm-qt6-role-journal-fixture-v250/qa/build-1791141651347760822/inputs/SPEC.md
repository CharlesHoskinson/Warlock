# Protocol and evidence

--run chooses window-modal; --run-application-modal chooses application-modal. --describe/--validate-command are pre-QApplication CPU entrypoints. Native profiles require the complete private QA gate. stdin is SEQ command [A|C], canonical decimal1..INT64MAX, strictly increasing per process, no unknown command/role/extra tokens/embedded NUL or >511byte unterminated line. Malformed input records refusal, retires fixture roles and exits6. Quit/complete EOF retires P,D,B,A,C; independent rootC stays alive during close-owner. QApplication does not autoquit on the last window.

JSONL schema1 carries event sequence, PID/start, monotonicUs and command requestSequence. QObject-owned callbacks capture immutable role instance and check current object; deferred deletion signals retire that exact captured instance, never a recreated slot. Resource IDs are actual wl_proxy_get_id(surface) from pinned QNativeInterface::Private::QWaylandWindow::surface. The private header is an explicit exact-Qt-version ABI dependency, not a portable public API.

Native QWindow input and propagated QWidget input are distinct events (window-button/key-* and widget-button/key-*). Each records sourceSurfaceId from the actual receiving native QWindow and Qt timestamp/source/buttons/modifiers or native scan/virtual/modifiers. QWindow event is Qt platform delivery, not native compositor receipt; QWidget event is actual toolkit receiver. Drawing markers/allocation/state events are queued/client observations only. Raw Wayland trace/native scene and actual screenshots are separate future qualification.
