# Menu integration with the shared window engine

This derivative connects the bounded menu component to the existing Shell/Effects
command allocator. `NativeProvider.fromShell` builds supported Restore/Minimize
rows from admitted, ready native projections and canonical ownership roots.
The caller supplies registered provider, capability generation and presentation
output identities; no title or application label identifies an action target.

`MenuBridge` captures the current engine stamp and registers each generated
native command before returning it for forwarding. Menu receipts retain their
original full tuple independently of the engine's latest transaction. Every
ordinary taskbar dispatch passes the same outstanding-target guard. The owned
`TaskbarShell` derivative integrates these paths; it does not create a parallel
request sequence or native authority.

The native callback visits the menu registry before the singleton Shell receipt
gate. A common strict outcome shape check also protects ordinary taskbar
Activate/Minimize/Restore receipts; absent menu correlation does not reject a
legitimate ordinary taskbar receipt. These checks assume the existing authenticated,
bounded broker channel. JSON shape checking is not authentication.

The shared surface controller must publish a closed popup and retire its lease
in the same atomic commit that forwards a selected window command. The native
host refuses effects while its popup remains logically open. New context-menu
mode, manager-checked gestures, menu-specific lease renewal, renderer focus and
outside-click handling still need integration and native qualification.

Retaining an original mapping enables a delayed authentic receipt to resolve its
operation; it cannot recover an outcome lost with the broker. Current broker
transport has no qualified read-only operation journal query. Matching a fresh
window state does not establish that the old operation committed. Unknown remains
blocked until an original-key terminal receipt or a separately reviewed recovery
policy permits progress.

This guard retains menu-origin operations. Ordinary taskbar operations still use
the engine's singleton transaction; retaining and reconciling all operation
origins is a separate authority integration gate.

Compiled external fixtures and source hashes are frozen separately from native
GUI acceptance in `qa/implementation-manifest.json`. No mandatory roadmap or
right-click requirement is completed by this adapter's CPU checks alone.
