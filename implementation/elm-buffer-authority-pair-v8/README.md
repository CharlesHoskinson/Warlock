# Authority pair V8

Compile-only derivative of the unchanged V89 authority plugin, policy headers,
adapter modules, and model/QA sources. The exact owning core is the frozen V7
buffer-selection component. Public owning headers are captured before compilation
and checked against V89's inherited dependency capture and the V7 component.

The protected build compiles captured authority and headers, checks required core
and plugin symbols, and verifies original/captured inputs after compilation. The
pair manifest binds the actual core binary and rebuilt plugin. Inherited model
evidence remains inherited; this build does not rerun or expand its qualification.

No host is assembled, installed libraries are unchanged, and no GUI is launched.
Native effects, parent viewport mapping, failed V6 mode restoration, rotation,
multi-output input, accessibility, and release acceptance remain unqualified.
