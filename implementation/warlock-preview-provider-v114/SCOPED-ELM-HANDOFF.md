GUI113 extends the existing immutable PreviewPresenter with a native controlled
realm and scoped preview detachment. It creates no second policy. The existing
legacy host routes and permanent retirement path remain usable. Controlled
Popup/shared-host/WebKit/Core routes are still inactive; full release is open.

NativePreviewRealm decodes a bounded native grant and a closed realm envelope
with lossless positive UInt64 identities. Incoming events require the original
binding/receiver epoch. The Presenter additionally validates every inner source,
catalog, lifecycle, metadata and retirement binding. Bare legacy input refuses
once a controlled grant is enrolled. Outgoing proposals retain the same native
realm and carry no renderer-issued ordinal. Binding reconciliation uses the
actual canonical binding:lifetime:session:frontend identity, which the C owner
checks before issuing a ticket. NativePreviewDetachment decodes exact native
seeds and retained final deliveries; zero request floors are valid for cold
members. Neither decoder contains a permanent Native Retired observation.

Trusted quarantine immediately revokes demand/display in every lifecycle while
retaining original known jobs, packet retirement and cold metadata entries. A
native scoped seed must match the same binding/epoch/member and original Elm
request floor. Terminal ACKs remain in original order before distinct readiness.
The member remains until an exact contiguous final delivery matches retained
readiness and lifecycle settlement. The bounded 256-member completed map allows
an exact older duplicate to re-ACK; changed old facts and gaps refuse. Ordinary
UI/catalog closure cannot discard cold scoped obligations. After strict native
close of the empty realm, a greater native epoch can enroll the still Active
subject on the same Native grant. Permanent observed/settled chronology and
global catalog chronology remain retained; only the completed realm's delivery
prefix and completed scoped map change. closeRealm is a trusted native-close
notification, not an independent physical-close detector or a renderer action.
