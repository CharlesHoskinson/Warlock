The coupled model covers the original client capture resource target. Its
producer/export records and reply bytes come from the actual plugin19 engine
and wire encoder; reply admission uses the actual GUI105 decoder. The original
capture intent and native binding are prepared through an authenticated
synthetic Native socket. Engine execution in this replay is in process.

| Model field/event | Concrete observation or operation |
| --- | --- |
| producer | Original request occupies the actual capture map and owns its image |
| exported | Original map row owns its independent sealed export descriptor |
| other | A different request occupies the capture slot; original operations must preserve it |
| locked | Supplied native lock observation; producer retirement uses the production guard |
| sequence | Production resource engine counter, advanced only after response construction |
| cursor | Actual GUI resource decoder's accepted sequence |
| seenProducer / seenExport | Last accepted producer charge and export identity, independently of physical state |
| unknown | Original response lost or rejected; retained observations cannot establish a new outcome |
| status | Closed GUI status: Observed=0, Settled=1, PendingExport=2, PendingLock=3 |
| last | 0: no resource effect; 1: validated response; 2: committed response lost/rejected; -1: engine refused before mutation |
| Release / Retire / Observe | Actual scoped engine operation and actual decoder |
| LostRelease / LostRetire | Actual operation commits; returned response deliberately withheld |
| BadReply | Actual Observe response has an invalid status; decoder cursor must remain unchanged |
| BadTransfer / BadSubject | Actual engine target/transfer validation; an absent target's wrong-subject reply still fails original intent correlation |
| FailPrepare | Actual response preparation throws before native resource mutation |
| OtherCapture | Original producer/export already absent, then a distinct actual owned record is inserted |
| Confirm | Frontend transport confirmation is a resource stutter; C prefix effects have separate actual C/socket witnesses |
| history | Quint input history only; not implementation state or authority |

Binding, clock, subject, original capture request and transfer retain their exact
relations and lossless counters. Representative values are UINT64_MAX for the
native lifetime and 9007199254740995 for the export. Native time increases with
the actual native request serial; elapsed time and resource sequence gaps are
quotiented because this resource protocol permits cleanup after expiry. The
original capture deadline is unchanged. No capture eligibility is granted.

Opaque descriptor numbers and producer pointers are quotiented while actual
ownership and destruction remain observable. No new acquisition exists in this
resource model; the original capture model and C/socket witnesses independently
reject capture replay and preserve the original command bytes/context/deadline.
Local mapping/readers, Broker storage/proofs, actor incarnation facts, control
delivery/confirmation and GUI policy are outside this model. Backend zero does
not prove those obligations; their actual code and separate original checks
remain required. Sampling and matching traces are bounded qualification, not
exhaustive proof or native compositor capture acceptance.
