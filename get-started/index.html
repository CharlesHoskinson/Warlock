Integrate the CSS

Opt in with data-warlock-design="v1" on the root element and choose data-theme="night", dawn or high-contrast. Load the shared cascade order first, followed by tokens, fonts, site and effects. This example works from this page:

<link rel="stylesheet" href="../assets/shared/layers.css">
<link rel="stylesheet" href="../assets/shared/tokens.css">
<link rel="stylesheet" href="../assets/shared/fonts.css">
<link rel="stylesheet" href="../assets/shared/site.css">
<link rel="stylesheet" href="../assets/shared/effects.css">

The Elm Architecture

Warlock’s GUI uses The Elm Architecture: a model, view, messages and update, with commands and subscriptions connecting the interface to its host. Explore the component architecture.
