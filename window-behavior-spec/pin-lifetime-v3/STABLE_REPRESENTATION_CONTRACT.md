# Exact public stable ID representation refinement

Actual accepted C1 clients and the unchanged taskbar helper carry stableId as a canonical lowercase hexadecimal string; the preserved integer-only draft incorrectly refuses it. Do not coerce to JavaScript Number, decimal, float, or inferred schema. Select and retain the exact string (zero `0` or 1..16 hex digits with no leading zero), representing uint64 without precision loss. Native capture compares exact string to std::format("{:x}", owner->m_stableID); a native token response must equal that same captured string. PID remains a positive exact integer bounded to int32. Address remains exact canonical lowercase hex string. No other capture/helper/window authority or error gate changes. Numeric/string mismatch, boolean, overflow, noncanonical spelling, foreign reply, or missing field is refusal. This correction is proved before changing draft native, CLI and menu code; prior draft and actual source-backed counterexample remain.
