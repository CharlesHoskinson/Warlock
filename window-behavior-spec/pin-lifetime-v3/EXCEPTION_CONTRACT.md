# Native exception boundary refinement

Before V25 implementation: snapshot/receipt allocation may fail after an owning core call. Track invocation BEFORE every call, retaining the last phase and immutable before snapshot outside execute(). Any later snapshot/stacking/serialization error is incomplete and possibly partial. No rollback, retry, fallback window, or feedback success. A Lua transport/serialization error after entering perform() is conservatively phase unknown/possiblePartial; it must not become a validated no-write refusal. Root-reviewed helper consequently yields Uncertain. Preselection/parsing errors before perform retain validate/no-write refusal. Snapshot failure before any core call refuses without native authority. Exceptions are not proof of actual mutation.
