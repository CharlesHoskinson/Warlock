A2 requires actual source-bound qt_modal_probe event snapshots before/after every route. Root alone runs native QA. Immutable probe sources/code, actual compositor PID/start/private scope/socket, selected exact window lifetime, actual pointer hit or Seat/core owner, frozen route producer and exact stdout plan remain separate host/product gates. The pure decoder cannot create these authorities and accepts only data from the host's observed queries. CPU data cases are not native acceptance.

Before snapshot must be an exact typed prefix of after snapshot; no eviction, reorder, substituted/mutated prefix or extra event is accepted. Pointer suffix exactly BTN_LEFT(272) down then up, both genuine same captured hit owner and integer interior cursor, typed event timestamps and cancellation flag. Require complete normal keyboard producer and final zero modifiers separately, without treating those as event proof.

Event log bounds are actual immutable probe capacities256 buttons/512 keys; prefix eviction is a refusal, not a retry. Missing/up-only/repeated/reordered/wrong code/wrong member/stale prefix/foreign lifetime/numeric boolean aliases refuse. No new synthetic counter or active/window-label fallback supplies an event identity. Keep original input routes, native receipt and all14 window/peer/focus/lifetime/stacking/reload checks; episode proof is additional. Full pin popup, helper registry, family/minimize/monitor/reduced/feedback/max+pin/fullparity remain separate requirements.
