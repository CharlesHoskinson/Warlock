## Retirement boundaries

Retirement requires the exact selected Process/lease, full original factory/provider/lexical tuple and generations, current source and context guards, actual original normal actor lifecycle, historical live kernel proof, joined worker, both actual EOFs, exact durable receipt, actual gone PID/start and an idle public Process property. Current menu authority is not required to preserve a historically closed actor after dismissal; it cannot be derived from that history.

After each reentrant getter and disconnection, the selected record and original guards are rechecked. A matched fault cannot be sealed as normal history. Closure and receipt are checked again after disconnect callbacks. A reentrant different record is neither erased nor faulted. Retirement removes only the exact closed registration, retains its historical accounting, revokes current success/kernel authority and does not control any child.

A refusal before commit leaves the old selected registration unless independent reentrant code changed it. Connections already disconnected during a later callback refusal are not rolled back; all actor conditions had already been normal and closed, and no changed-command launch is authorized by the refusal. No atomic rollback or callback-free operation is claimed. Final Provider source failure after a successful retirement can return an error after the old record is removed; it still cannot authorize a new launch or infer success.

## Hint boundaries

Worker code is unchanged and accesses no QObject. Registry notifications run on the owner thread and call only the optional production callback. That callback queues through real guarded provider/process allocations and revalidates the original source and lexical contexts before emitting. It carries no kernel, receipt, PID, exit, EOF or success flag. QML ignores an old QObject/lease before querying; current repeated hints cannot publish twice. The additional hints after matched wrong-thread fault drain and expired delivery preserve the existing fault assignments and budgets exactly. Native signal/watcher duplicate rules remain strict.

No timer, extra helper run, control, sleep, relaunch, budget extension, source cache, stale VMA union or command fallback is added. The previously existing nonblocking worker join timer is unchanged. Owner-thread source checks retain their existing cost; no smoothness measurement is claimed here.
