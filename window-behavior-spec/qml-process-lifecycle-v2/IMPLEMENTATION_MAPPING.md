# Proposed Process observer implementation and remaining proof gates

This is a formal/source review packet before any runtime observer or QML launch semantics change. Approved popup provider V4 remains a distinct immutable source component.

| Abstract fact | Required actual observation |
|---|---|
| armId Process/streams/engine | Genuine fixed lexical Process and two StdioCollector allocations, guarded public property equality, actual contexts/factory/activation, selected source/image/config and exact original command/JSON |
| dynamic PID/start | Actual positive integer QVariant processId on started, with owned live kernel lifetime before/after and exact parent/process group/UID/cgroup/namespace |
| fixed kernel fields | Actual final executable/hash/argv/selectors/direct entry equal original arm witness, not rebound from modified Process.command |
| started/exit | Exact actual native Qt signals; guarded matched allocation plus provider-issued lease; exit carries actual integer code and QProcess::ExitStatus |
| stdout/stderr EOF | Each actual collector streamFinished plus immutable bounded actual text/bytes; no caller completion flag |
| gone | Same registered child lifetime absent after normal exit, without signalling; reused PID refuses |
| strict receipt | Exact unchanged direct helper/capture schema, private owned evidence file and kernel/owner projection; no replacement helper |
| current | Full current captured owner/menu nonce/context/activation/row, actual source-bound input episode and separate native Seat/layer witness |
| normalLife | All actual started/kernel/normal exit/both EOF/gone facts, retained even when menu cancellation revokes success |
| accepted | Normal lifecycle, code0, exact strict helper receipt and still current full captured source/owner tuple |

The model's true kernel/strict-receipt parameters are specifications of complete concrete conjuncts. No QML Boolean, nonce alone, successful command write or normal driver exit can supply them. Observer APIs must receive actual lexical objects and bounded original command data; provider generations and invocation leases are allocated internally. Observer never launches, stops, kills, detaches or replaces a helper.

Source evidence: installed Quickshell.Io qmltypes declares actual Process.started(), exited(int,QProcess::ExitStatus), QVariant processId, DataStreamParser pointer stdout/stderr, StdioCollector bool waitForEnd and streamFinished(). Source-local Process::onFinished drains streams before exited and clears its underlying QProcess; local documentation warns reload may terminate it. That local source is attribution, with no installed revision equivalence claim. Observer supports any EOF/exit ordering and records real failure when live kernel proof is missed. No retry or waiting budget extension repairs a missed witness.

Before a runtime candidate, actual CPU Qt tests must establish public typed Process/parser property reading and guarded pointer return semantics under callback-driven replacement/destruction. A returned unanchored QObject pointer may not be dereferenced or treated as allocation authority. A live lexical collector QPointer before/after each property getter is necessary but cannot by itself authenticate a new returned object. Exact native type/property definitions and safe comparison to already guarded allocations require their own inspected public API implementation and CPU retirement tests. Missing supported access refuses.

Additional CPU tests must use a genuine QProcess child and kernel before/after identity: actual start and all signal orders, both streams/EOF, real normal refusal versus crash, short-lived child refusal, replaced PID/process/collectors/source, old lease callbacks, cancellation retaining cleanup, malformed/duplicate/nonfinite/wrong typed receipt, owner/config changes, and safe lease exhaustion. They cannot accept the installed QS implementation or claim observed QS reload behavior.

Future root private GUI must establish actual installed metaobjects, actual direct unchanged helper/capture launch, registered normal exit and both EOF/kernel-gone for every real route, correct copied source/import/env/loader closure, and source-specific actual input episode before any completion. Delayed menu, cancellation/recreation/reload/family/minimize/restore remain required. Preexisting immutable B controller is not a complete runnable campaign; any integration occurs in a fresh derivative after reviews.
