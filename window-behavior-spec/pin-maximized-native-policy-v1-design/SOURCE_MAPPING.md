## Planned fresh source components after design review

`campaign_b_cases.py`: separate fixed scenarios, raw-before-assert controller, strict per-case allowed-change projections, no original14 rewrite. `campaign_b_observer.cpp`: additional read-only metadata and explicit windowAt calls plus bounded actual fullscreen/workspace native event observations; built against unchanged V3 headers with source/ABI/dependency closure. `campaign_b_decode.py`: typed tokens/scalars and complete before/post confirmation; no bool/float/int aliases or generic membership matching. `campaign_b_capture.py`: full literal ancestral source/mode/link/directory union and actual fail evidence. Presentation and a two-output host are separate prerequisite components, not silently folded into the observer. No product delta is proposed.

The exact observer code, permissible calls and typed schema must be reviewed before implementation/load. A borrowing weak handler over a uniquely-owned object must never `.lock()`; observer access must use existing owning algorithm lifetime and only safe public read APIs. Query failure/unknown state is raw refusal, never fallback authority. CPU/model tests verify these obligations but do not grant native reachability.
