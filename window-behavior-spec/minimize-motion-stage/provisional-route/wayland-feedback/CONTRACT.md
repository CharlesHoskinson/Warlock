# Wayland surface presentation producer

A record is admitted only for an exact synchronized token/identity/source/output snapshot, followed by a feedback request before the corresponding surface commit. Qt beforeSynchronizing blocks GUI mutation; afterRendering precedes the RHI endFrame commit. Qt owns display reading and default event-queue dispatch. This module never dispatches, roundtrips, polls, or consumes the display file descriptor.

Each request has a unique monotonic local frame sequence and a window generation. Pending feedback is bounded to 128; no admission is made when capacity is exhausted. Presented callbacks must name the captured output, have a timestamp in the advertised compositor clock domain, and exceed the last accepted presented sequence for this generation. Discarded, duplicate, old-generation, wrong-output, and out-of-order callbacks cannot supply origins. Replacement/destruction retires outstanding feedback before any new-generation record. Missing protocol, output mismatch, or unavailable surface remains unavailable, never synthesizes presentation.

The callback reports that the compositor presented the surface content update. The synchronized item rectangle is frontend scene geometry; expected atlas digest and expected global rectangle remain supplied metadata. This does not independently prove GPU texture pixels, output scanout, or atlas byte provenance. No raw record is directly admitted to GlobalRoute.present; a coordinator must match an immutable verified source and exact submitted frame, and convert measured scene coordinates using validated output/layer geometry. Native authority remains with fresh exact ID/PID/family validation. This producer has no native operation API, focus, painted contents, input interception, or accessibility changes.

Qt's QPA nativeResourceForWindow("surface") and nativeResourceForScreen("output") are private ABI. This isolated candidate requires exact Qt 6.11.2 and public wl_protocol APIs; no private C++ object-layout casts. wl_surface/output handles are sampled while GUI is blocked and used only for the matching render frame. The compositor registry is bound asynchronously on Qt's default queue. Unknown/removed protocol retires readiness. Native feedback and pixel/cadence tests require a coordinated GUI slot.
