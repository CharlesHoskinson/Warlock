# Exact current-geometry gesture retirement before motion capture

Fresh V12 native integration requires the paired reader interruption API and
Snap Lua clear-state event. Immutable V11 and every prior native attempt remain
unchanged. This contract is specified before implementing the capture seam.

A metadata observation cannot retire a gesture. First reserve every freshly
validated exact family identity under the same current receipt/controller lock
used for irreversible destination and native family effects. An obsolete
worker, incomplete family or newer peer receipt cannot enter retirement.
Do not infer a physical release, call the old drag_finish cancellation path,
snap, restore press geometry or alter pins to obtain a snapshot.

Probe the required retire_gesture_current capability and call it for every
fresh exact address/stable-ID pair. Failure/absence/malformed response aborts
all source capture; there is no compatibility fallback. The callback clears
only matching gesture staging and keeps current valid geometry. A batch can
retire an earlier member before a later refusal: this is recorded, never rolled
back or mislabeled atomic gesture cancellation. No PNG capture follows refusal.

After all retirement calls succeed, requery complete current family identity,
relations, geometry and pins. The exact family scope must remain unchanged and
the reservation must still own it. First capture uses this post-retirement
current geometry and flags, not the press rectangle or stale initial query.
Resolve a relative/activate intent against the post-retirement native state.
Native presentation/endpoint authority is granted only through the existing
fresh complete family/identity/source/presentation guards. Retirement is not
readiness or native minimize/restore authority.

For a retained scene, original immutable source pixels/order remain owned by
the renderer; changed geometry causes safe refusal/replacement rather than
source reset. Full atomic scene replacement and arbitrary mid-flight flag
changes remain separate open gates. The service does not call retirement inside
its unowned asynchronous family lookup or allocate a source before this seam.
An already running empty passive producer process is not a snapshot visual;
no scene is seeded until retirement and capture validations finish.

The private native campaign must pin both fresh native library and paired Snap
Lua, with actual held gesture, current-geometry export, preview/minimize/restore,
real later release, normal cleanup and exact independent main preservation.
No native acceptance, service deployment or GUI launch is implied here.
