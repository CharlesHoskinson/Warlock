# Production default renderer promotion

This fresh source derivative inherits accepted GPU V9 and actual private V11's
44 original full-image comparisons, 18 default read pairs, four configuration
binds and preservation/cleanup evidence. Diagnostic raster acceptance is not
native family, authority or cadence acceptance. Frozen V9/V11 remain immutable.

Ordinary launch (no CLI arguments) selects exactly the accepted four-nearest
sampler, per-layer RGBA8 explicit over and half-open pixel-center full-screen
coverage. Default raster diagnostics use that same repaired pipeline without an
experiment flag. Explicit existing manual/over experiment flags remain available
only in the exact raster/causal/private-readback scope. No ordinary launch flag,
stdin command, environment or pipeline configuration getter may convert a
production launch into a raster/no-authority launch. The raster mode bit is const
after construction; native validate/start checks continue to use that bit.

Pipeline selection does not grant native authority. Native readiness and endpoint
authority still come solely from the unchanged exact token/family/context/output
generation and actual swap/presentation CommitLedger protocol. Shader failure,
missing source, wrong coverage/uniform/viewport/program, stale generation or
resource teardown failure refuses/cancels; there is no ordinary fallback to the
old hardware-linear/fixed-over pipeline. Raster validation and native start remain
refused regardless of successful repaired pixel/configuration checks.

Accepted shader text, PixelCoverage math, every source/control/ordered-prefix
binding, causal/default readback, ledger, original oracle and tolerance remain
byte-identical to V9. This derivative changes default selection, immutable mode
storage, selected-role observation and source/offline tests only. Both production
and diagnostics retain configuration getters as non-authority metadata.

Required native acceptance is a fresh default-path original 44-image campaign
without an experiment flag and ordinary no-argument actual Service V12 family,
preview/cache/restore, normal renderer/actor retirement, and continuous reversal.
Reduced motion/failure/output replacement/cadence/recovery remain separate work.
No installation, main reload/write or native launch grant is implied here.
