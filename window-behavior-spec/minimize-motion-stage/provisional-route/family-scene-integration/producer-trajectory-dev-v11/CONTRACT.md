# Continuous retained family trajectories

This fresh primitive addresses the remaining velocity requirement. The frozen
V10 renderer remains unchanged. The actual V3 run already proves its position,
ownership, presentation and retirement properties; the independent velocity
audit shows its linear retarget resets velocity by more than 2,000 logical
pixels per second. Passing position continuity is insufficient for this gate.

A new trajectory must start at the exact latest accepted displayed rectangle
and its analytic velocity, per output generation and ordered immutable member.
Submission, an old token, another output, or an estimated target never supplies
the origin. Every member uses one common positive duration. Initial transitions
start at zero velocity; the endpoint has exact target geometry and zero velocity.
Repeated reversals preserve both position and velocity at their origins. They
reuse sources and never authorize native effects without existing validation
and actual presentation gates. Reduced motion retires this path normally.

The proposed cubic Hermite curve carries the origin derivative and ends at zero
derivative. On reversal it may briefly continue the old direction before turning;
that is necessary to preserve nonzero velocity. Width and height must remain
strictly positive. The common duration is reduced, without clamping the origin
velocity, when the shrinking tangent could exhaust a dimension. Unsafe or
unrepresentable input refuses. Diagnostic static sample mode retains its existing
linear geometry so the original raster oracle is unchanged.

The primitive and bounded formal/numeric checks prove no renderer integration,
display cadence, application compatibility or native authority. Integration must
store trajectory derivatives in immutable submitted frames, and retain them only
when the exact successful swap and current output presentation are accepted.
Position origin and velocity origin are taken from that same immutable frame.
All old strict reversal/raster/resource/native gates remain required, alongside
independent new derivative and positive-size evidence. Actual default diagnostic
raster, ordinary continuous animations, mixed outputs and reduced motion require
fresh campaigns after source review.
