# Design abstraction to native source obligations

This is the required mapping for a future implementation; no new field is asserted to exist today. Raw/public JSON values must be typed, finite/ranged and source-bound, never guessed from geometry or weak pointer address. Python Boolean/float aliases cannot satisfy integer/PID/mode fields in a fresh report decoder.

| Model field/event | Exact source / required actual meaning |
| --- | --- |
| token owner/address/stable/pid/generation | V25 PinLifetime strong captured PHLWINDOW + actual public stable ID/PID and exact per-owner lifecycle generation, address equality only insufficient. Existing public receipt generation maps to model generation. |
| token session/compositor/start | Actual compositor runtime session plus PID/start lifetime, no plugin/client synthetic authority. |
| token epoch/incarnation | Existing V25 operation/plugin lifecycle invalidation; unload/reload changes incarnation and callbacks must recheck. |
| token source / capability | New reviewed matching core API/header/ELF/source binding from actual loaded modules; capability Boolean abstracts validated version, not accepting a flag. |
| windows.mode/client | Per-target actual `SFullscreenMode.internal/client` queried through owning FullscreenController, not isFullscreen covering-winner inference. Values NONE0/MAX1/EXCLUSIVE2; unknown refuses. |
| windows.floating | Actual core m_isFloating; native MAX and restored tiled owner can remain false. |
| windows.pinned/maxOrigin | Actual independent core m_pinned intent plus new owning native MAX-origin record. Plugin never writes either. Effective band is separate. |
| windows.rect | Core real/current and goal geometry must both be conserved for pin. Model's single positive Rect abstracts both; native adapter must not lose animated/native geometry differences. |
| windows.restore | New core-owned pre-MAX native return box (position+size), original float state, actual target/group member lifetime and tiled layout return authority. `known` means complete validated core record, not nonempty JSON. Positive target/layout/generation tokens abstract exact owning records, not new service counters. |
| workspace/output | Actual window and target/space monitor/workspace must agree; native pin cannot invoke legacy monitor-active workspace assignment. Transfers are independent owning operations with validated handler migration. |
| live/visible/special | Actual mapped/hidden/minimized/normal-space eligibility, not merely existence in a cached public list. Hide/Show abstracts service-owned minimize/restore only after genuine authority; does not bypass native settlement. |
| before/guardedWindow | Full captured owner and family semantic snapshot before each native callback, including modes/restore/membership/native focus, not just requested pin value. Model compares every other window; implementation must evidence no selected operation writes peers and invalidate incompatible observed context. |
| Pin(Result) / calls / partial | Owning `Config::Actions::pinWindow` native invocation and real result plus pre/post sampling. Exception/failed native result retains invocation accounting and actual changed state, no rollback. |
| roots / Raise | Actual persistent WindowState bottom-to-top order, parent/transient units and exact strong owners; no plugin render list that ignores native input stack. |
| edge/effective/renderOrder/inputOrder | Shared core actual modal/X11-transient ancestry, same normal workspace/output and live lifetimes; fixed 1→3→4 chain abstracts cycle-safe bounded native traversal and sibling precedence. Render and hit-test use same protection; main/popup/final passes each owner exactly once. |
| ExitMax/EnterMax | Genuine owning FullscreenController/handler transition with pre-entry restore capture/exit use; mode changes are not part of pin action. Ordinary replacement vs protected coexistence policy remains explicit review decision. |
| Focus / modal_focus chosen | Genuine explicit native focus request; deepest visible eligible modal descendant. Pin action does not focus. No original-owner refocus to repair a refusal. |
| modal_focus current/root/child/nested/graph | Exact root/session and each actual strong member lifetime/parent link/surface from current native graph. Even valid replacement changes witness. No weak-only address alias. |
| modal_focus guards | Native session lock, exclusive layer, Seat grab, owner/leaf nofocus/focusability/X11/surface, visible workspace, fullscreen ownership and bounded graph validity. Current Boolean abstraction is not permission to skip source guard. |
| Commit / focus / seat | Native fullWindowFocus/rawWindowFocus/rawSurfaceFocus accepted target and actual Seat keyboard surface; Seat refusal cannot yield accepted result. Existing surface constraints and priority rules remain. |
| FollowUp / cursor / forced / monitor | ConfigActions switchToWindow uses actual accepted target after guard recheck; original shadowed owner must not be warped/forced/migrated. Model forced records temporary forcedFocus target; actual implementation preserves lifetime during simulateMouseMovement and resets it afterward. |
| reduced | Optional feedback only; ordinary/reduced-motion pin intent persists. No change to service reduced validation/cancellation authority. |

Important gaps requiring implementation evidence: per-target restore record construction; group current-member switching; scrolling layout capture/restore; full animated rectangle conservation; native layer alpha and render/hit/decorations coherence; actual Seat surface rejection; typed source/API handshake; legitimate transfer coordinate mapping. This design does not claim those obligations are implemented or accepted.

Focus acceptance refinement: `modal_focus.Commit(Result)` independently records actual core-owner and Seat observations; `Result.ok` does not override mismatch. The model's integer `seat` denotes exact selected native keyboard surface identity, NOT public active-window ID. Actual implementation must compare `g_pSeatManager->m_state.keyboardFocus` / its native resource to the selected owner's expected live `wlSurface()->resource()` and current core focus owner/surface, require `g_pSeatManager->m_keyboard`, and preserve both observations before asserting acceptance. Session-lock/Seat-grab refusal inside rawSurfaceFocus remains a partial native outcome if core focus already changed. `keyboard`, `partial`, ordinary `ClearChild/HideChild`, `UnrelatedRequest`, and post-commit guards/lifetimes now explicitly model those boundaries. No callback repairs a partial state by forcing a surface or rolling core focus back.
