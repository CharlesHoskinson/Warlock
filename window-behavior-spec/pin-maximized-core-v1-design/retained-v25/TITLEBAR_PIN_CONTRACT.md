# Reserved Pin button event boundary

The inherited generic decoration handler focuses and raises the caption owner before checking buttons. That cannot establish the Pin operation's focus origin for an unfocused reserved Toggle pin click. For the reserved Pin action only, inspect the actual same decoration button geometry and captured strong owner before generic caption focus/raise. Cancel that physical down for the decoration and retain its matching release cancellation. Invoke the captured synchronous Pin action once with the existing core and Seat focus routes unchanged. A stale/hidden/undecorated/invalid box does not invoke Pin. No active/address fallback, focus repair, queued retry, or generic late reserved branch may create authority.

Other decoration buttons and ordinary caption actions preserve their inherited handlers. The Pin event still requires the genuine same private native hit/cursor and physical down/release; this specific handler is not a general replacement for caption focus. Native Pin and stacking guard snapshots remain mandatory after callbacks. This is an explicit frontend semantics refinement; the original entry-only focus proof and compiled pre-refinement candidate remain retained.
