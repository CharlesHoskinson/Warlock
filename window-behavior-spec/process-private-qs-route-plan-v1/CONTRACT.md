A fresh read-only QML diagnostic must sample `observePopup(root,toggleButton,pinPopup,Quickshell)` using those actual lexical objects. 2. Existing B calls `case.release(True)` after driver writes/exit. Reviewed A2 episode component has only titlebar/SUPER+P/SUPER+CTRL+T routes and native window-owner semantics. It cannot authenticate popup layers or Return unchanged. A fresh B-specific episode profile must model exact mouse/keyboard suffix, actual layer/Seat owner and captured popup tuple. Existing B probe samples layer ownership for mouse events but contains no key listener. Fresh read-only probe composition must retain original sources/listeners and add bounded keyboard rows with event-time layer identity. No layer is converted into a window token.

These two gaps require a narrow fresh contract/model/source mapping before controller/QML/probe implementation. Preserve old B model and A2 component exact. No new terminal-retire or helper semantics are proposed.
