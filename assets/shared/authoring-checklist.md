# Page checklist

1. Start from page-template.html and replace its example title, article, breadcrumb and index with meaningful content.
2. Set paths relative to the staging root, select the correct current navigation link and retain the complete navigation.
3. Use shared tokens, layered styles, semantic HTML, underlined links and visible focus. Preserve access without JavaScript.
4. Verify local links, fragments and assets; check narrow width, keyboard access, text enlargement, forced colors and reduced motion.
5. Record assets and source provenance in the owning package manifest.
